# shared 模块

## 目的

承载跨模块复用的无 UI 契约，当前仅提供站点路由形状。

## 职责

- 定义 `Route` 类型，供 app 路由解析和主题装配使用。

## 非职责

路由解析、导航副作用、React 组件、CSS 和主题资产。

## 公开接口与输入输出

`Route`：home、browse、albums、album 和 not-found 的判别联合类型。

## 允许依赖

无。

## 状态及资源生命周期

纯类型契约，不持有状态或资源。

## 主要文件

- `routing.ts`：路由形状。
- `index.ts`：公开入口。

## 扩展和验证方法

新增共享契约前确认它确实被至少两个模块消费且不含 UI 或业务流程；app 路由测试继续覆盖运行时解析。
