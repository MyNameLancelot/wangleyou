# themes 模块

## 目的

运行时主题选择和完整主题应用装配：提供 Beach、Grassland 两个互不依赖的站点 UI、主题读取、切换与偏好持久化。

## 职责

- `index.ts` 只提供 `THEMES`、`DEFAULT_THEME`、`THEME_STORAGE_KEY`、`isThemeName`、`readTheme`、`applyTheme`、`nextTheme`、`initTheme`。
- `beach/`、`grassland/` 各自拥有完整 JSX、CSS、装饰与资产引用；目录间禁止导入，也不得消费共享 React UI。
- 两套主题均不渲染常驻全局顶部导航；各自在页面内容层实现毛玻璃主题开关：首页位于第一屏右下角，其他路由位于页面顶部右侧。仅手机宽度（≤600px）的留影列表页 `#/browse` 固定该按钮在既有安全区位置；相册详情、其他路由以及 PC、平板继续随所属内容滚动离开；查看器不提供主题入口。按钮默认只显示 `lucide-react` 的循环图标，毛玻璃圆形仅包住图标（20px 图标配 32px 圆形），命中区域保持 44×44px，悬浮或键盘聚焦时展开为约 112px 胶囊并显示“主题切换”；玻璃表面不使用白色描边或高光边。
- 查看器不是主题 UI：两套主题都不实现、不包装、不复制查看器，只在会话存在时挂载共用组件 `MediaViewer`（来自 `media-viewer` 模块的公开入口），并把手里的 `props.session` 与 `props.commands` 原样传入。查看器的类名、样式与功能都由 `media-viewer` 模块决定（对齐库官方 Full-blown 示例），主题不得覆盖 `.viewer`/`.yarl__*` 类名、不得改插件集合、不得写入自己的查看器 CSS；查看器内部的键盘焦点环固定为白色，也不随主题变化。
- 两套主题各自在首页第一屏和第二屏右上角实现一个随屏移动的背景音乐按钮，两个入口共享该主题音乐组件内唯一的 audio、播放副作用与 playback 状态；第一屏音乐按钮与右下角主题按钮使用相同右侧安全区基准，第二屏不显示主题按钮。各入口命中区均为 44×44px，音乐可见毛玻璃圆形与主题收起表面均为 32×32px。播放态使用普通音符，暂停态使用降强调的斜杠音符，不渲染播放波纹；hover/focus 时只把图标组合放大约 10%，不改变背景圆形或命中区，减少动态时遵循全局即时过渡规则。刷新后自动播放被浏览器拒绝（blocked 保留播放意图）时，音乐组件监听一次性首手势（指针按下或键盘，音乐控件内部手势除外）并直接用同一手势重试 `play()`；音乐按钮自身在 blocked 状态下的点击同样重试播放而不翻转意图；dock 通过 `data-music-status` 暴露 `playing|paused|blocked` 供用例与调试。
- 两套主题各自实现首页第二屏交互，不共享 JSX 或 CSS：照片点击写入本地播放意图并切换暂停/继续，暂停时在照片下方显示播放按钮；桌面端显示左右箭头，并支持按住鼠标左右拖动与触控板横向滑动换图，宽度 900px 及以下隐藏箭头并改用第二屏内的横向滑动换图。只有位移达到 56px 换图阈值才捕获指针，因此普通点击（含触摸板点按时的轻微位移）仍按点击处理；拖动结束的补发点击由指针捕获拦截，不另设点击守卫计时器。首页第二屏不提供查看器入口，相册与留影页的缩略图仍打开查看器。
- 两套主题各自实现留影页（`#/browse`）：hero 复用主题 `home-hero.webp` 头图，并在“留影”标题上方各自渲染指向 `#/` 的“← 返回首页”链接（44px 最小点击区、沿用全局焦点环），不形成常驻全局导航；手机（≤600px）不渲染该链接，返回依赖浏览器返回手势，文案在 hero 剩余可用高度内居中。内容胶囊只提供“全部 / 照片 / 视频”类型筛选，不显示媒体数量或年份数量。正文按年份分组列出**相册**（每个相册一张卡，沿用影像卡样式，说明条显示 `album.title` 与 `album.description`；手机端说明条只渲染 `album.title`，深色底框贴合文字长度并去掉分隔线，点击进入相册详情）；封面由主题私有 JSX/CSS 渲染为最多三层的右上错位卡片，直接采用 content 构建期给出的 `album.media` 顺序取前三个不重复可用缩略图。该顺序由构建期按 `topNN` 编号升序、其余文件名自然序确定，主题不得重新排序；各封面层以 `cover` 铺满可见框、不使用白色描边或投影，鼠标悬浮时不缩放，只有这一预览裁切不会改变相册详情与其他媒体的完整显示。左侧定位栏（标题“光阴刻度”，`aria-labelledby` 指向该标题）只保留年份按钮，不提供相册快捷链接、数量与排序说明；年份按钮 hover 使用与当前类型筛选相同的主题主色与前景色。浏览主体与 hero 文案使用同一内容边距与最大宽度，宽视口下定位栏与卡片落在同一内容范围内；桌面端使用左侧定位栏，900px 及以下隐藏定位栏并改用页面内年份快捷导航，360px 下无横向溢出。
- 两套主题各自实现相册详情页（互不导入）：头图首幅在手机与平板（≤1199px）压到桌面值的三分之二并同步缩小标题、副标题、引言与返回入口字号；桌面视口首幅高度收到 360–400px。图集使用 `react-photo-album` 的 `MasonryPhotoAlbum` 按媒体原始比例排布（照片用 `src`/`srcSet`，视频用派生封面 `poster`/`posterSrcSet`），列数、间距与 `sizes` 一律采用库默认档位（容器 ≥1200px 五列/20px，600–1199px 四列/15px，300–599px 三列/10px，<300px 两列/5px），主题不得覆盖 `columns`、`spacing` 或 `sizes`；视频缩略图通过库的 `extras` 插槽在正中叠加「中间凸起的玻璃按钮」式播放标识：半透明白色磨砂渐变（`backdrop-filter` 模糊 + 顶部高光与柔和投影形成凸起感），内部是 `lucide-react` 的实心 `Play` 图标、图标固定灰色（桌面 38px、手机 26px，命中区仍是整块缩略图）；不支持背景模糊时回退为更不透明的白底。标识由页面按媒体类型生成、不烘焙进封面资源，因此留影页层叠封面保持干净。每张照片以白色相纸相框呈现（`padding={8}` + 白底、8px 圆角、主题色轻投影），留白计入列宽；首屏至少完整可见 4 张；缩略图容器高度等于图片高度，不露容器底色；按钮在任何状态都不使用边框，键盘焦点用提亮 + 约 2px 上浮替代描边。手机（≤600px）不渲染“← 返回留影”链接，返回依赖浏览器返回手势，首幅文案在剩余高度内居中。
- 每套主题在自己目录内实现背景音乐音量控件：两个音乐入口各自渲染一个 44px 高、与音乐圆形右边缘对齐的横向滑块面板，默认收起，且只在音乐处于播放状态（`data-playing="true"`）时可用——鼠标悬浮、键盘聚焦（`focus-within`）或触屏长按 500ms 才展开，暂停时面板 `aria-hidden`、滑块 `tabindex=-1`、长按按普通点击处理。长按不触发播放切换，点击面板外或 Esc 收起，移动超过 8px 取消长按。面板仅含滑块（无喇叭图标），为音乐图标同色相的深色磨砂玻璃（半透明色染 + 26px 背景模糊 + `box-shadow` 投影，无白色描边；音乐控件包装层不使用 `filter`，避免隔离背景模糊取景；第二屏浅色背景上同样可透视），滑块自绘为约 2px 浅色细线轨道与纯白直角长方形滑块（高约 18px、宽约 4px、圆角 0）；拖动或方向键写入 `playback` 的音量状态，audio 元素只投影该值，不创建第二份音量事实。
- 通过 `document.documentElement` 的 `data-theme` 切换模式，偏好写入 `localStorage` 的 `wangleyou.theme`。

## 非职责

不持有路由或播放状态，不保存除主题名以外的偏好；主题间不共享 UI 实现。主题文案与背景资源由各主题目录自行定义，不通过共享常量导出。

## 公开接口

- 函数契约：`applyTheme(name, root?, storage?)` 返回实际生效主题；`readTheme(storage?)` 缺省与非法值回退 `DEFAULT_THEME`（海边沙滩）；`nextTheme(current)` 在 `THEMES` 之间循环（海边 ↔ 草原）。
- `contracts.ts` 只定义无 UI 的主题应用输入和回调；各主题入口实现该契约。

## 允许依赖

可依赖 content、playback、albums 与 shared 的公开无 UI 契约；可依赖 `react-liquid-glass-svg`、`lucide-react` 等无状态展示库；不得依赖 app、另一主题目录或共享 React UI。

## 状态与资源生命周期

首页主回忆分别记录悬停和区域内焦点，任一存在都暂停自动换图，焦点在内部控件间移动不解除暂停；用户显式恢复会设置临时覆盖，直到指针移出或焦点离开播放器。页面隐藏时记录回前台待恢复，回前台不自动计时。触屏横向滑动后用短时点击守卫忽略补发点击。两个音乐入口均通过 data-music-screen 接入首页滚轮切屏。跳到主要内容只聚焦 main，不修改 Hash 路由。

音频 effect 每次建立时恢复主题私有 `media/themes/<主题>/music.mp3`，清理时暂停并移除 src；播放请求在清理或暂停时失效，防止 StrictMode 重放或旧 Promise 回写新状态。visibilitychange 暂停播放并标记回前台待恢复；回前台后只有音乐按钮显式点击才恢复，不自动播放。

主题私有资产统一放在 `public/media/themes/<主题>/`：`home-hero.webp` 供首屏与浏览页头图使用，`home-memory.webp` 只作海边第二屏背景，`music.mp3` 由音乐组件引用。主题组件只写自己的相对路径字面量，并通过 content 的 `mediaUrl()` 获取 URL；不共享资源常量、不自行拼接 CDN，也不引用其他主题目录。

第二屏的左右箭头、播放按钮与进度条轨道使用毛玻璃表面（半透明色染 + 背景模糊 + `box-shadow` 投影，无白色描边），进度条填充保持主题色实色；`@supports not (backdrop-filter: blur(1px))` 时回退为更不透明的底色。

每套主题在首页两屏之间渲染一个主题私有的装饰层（`data-home-seam`，`aria-hidden` 且 `pointer-events: none`）：用第二屏背景（海边为同一张背景图、草原为同一段渐变）在交界带内做跨屏淡入。该层位于首屏之上、第二屏之下（第二屏 `z-index: 3`，层为 `z-index: 2`），因此只影响交界带、不覆盖第二屏底板与照片；`@supports ((-webkit-mask-image: …) or (mask-image: …))` 不成立时该层保持 `display: none`，退回两屏直接相接。

主题偏好状态只有“当前主题名”一项，来源是 `localStorage`，由 `App` 在渲染前调用 `initTheme()` 应用。背景音乐意图与实际状态由 App 的 playback 状态持有，主题 UI 不复制业务状态；每个主题音乐组件拥有自身 audio DOM 和页面可见性监听，卸载时移除监听、暂停音频并释放资源。主题存储不可用（隐私模式或禁用）时静默降级为无持久化。海边首页可使用主题私有第二屏背景图，作为首屏到第二屏的视觉过渡；该图不进入 `content`、相册页或查看器，也不被其他主题引用。

查看器资源归属：包装组件挂载时由库创建 portal、记录打开触发点、给其余页面加 inert 并锁定页面滚动；打开期间主题包装注册文档级 `keydown` 监听维护 Tab 循环；卸载时 portal 与其媒体元素一起销毁，滚动锁与 inert 恢复，焦点回到触发元素（触发点已移除则回退 `main`）。视频监听在挂载与媒体切换时建立、在清理时解绑，`ended`、`timeupdate`、`error` 只通过命令回写会话；旧媒体的异步结果不得影响当前项，关闭或切换后不再持有旧媒体事件、计时器与元素。

## 主要文件

- `index.ts`：主题读写与切换；`contracts.ts`：无 UI 装配契约。
- `beach/`、`grassland/`：完全隔离的主题应用、主题内部首页（`ThemeHome.tsx`）、页面内容层主题与音乐控制、内容页（`ThemePages.tsx`，含视频缩略图与播放角标）、图片状态、Token 与样式。查看器由共用模块 `media-viewer` 提供，主题目录内不保留查看器实现或样式。
- `theme.test.ts`：默认回退、非法值、持久化、存储异常与循环切换。

## 扩展与验证

新增主题：创建独立主题目录，独立实现其站点 UI、CSS、文案与资产引用，再加入 `THEMES` 并补齐主题及浏览器测试。只能导入无 UI 的公开领域契约，不能导入既有主题或共享 React UI。

验证至少覆盖：默认与非法值回退、存储异常、切换后路由/媒体/播放上下文保持、1440 与 390 视口、对比度、焦点可见、reduced-motion。
