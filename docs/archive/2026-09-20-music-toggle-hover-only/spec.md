# 音乐按钮仅保留悬浮放大规格

状态：已确认

## 目标

- 完全取消音乐按钮播放状态的循环波纹特效。
- 鼠标悬浮或键盘聚焦时，仅让音符图形轻微放大。
- 保留右上角位置、32px 可见圆形、44px 命中区以及普通音符/斜杠音符状态区分。

## 非目标

- 不改变背景音乐播放逻辑、资源、音量、视频阻断或清理规则。
- 不改变主题按钮及音乐按钮的位置、背景圆形尺寸或命中区。
- 不新增依赖，不合并双主题 UI。

## 用户确认的设计

1. 播放状态不再显示波纹或其他循环动画。
2. 播放与暂停分别使用普通音符和斜杠音符，无需额外播放态特效。
3. hover 和 `focus-visible` 时，音符与暂停斜杠作为一个整体从 20px 视觉尺度放大约 10%（约 22px），32px 圆形背景保持不变。
4. 放大过渡约 160ms；`prefers-reduced-motion: reduce` 下遵循全局不超过 1ms 的过渡时长并立即切换。
5. 触屏设备不依赖 hover，按钮的状态图标和可访问名称仍可独立表达含义。

## 验收条件

1. 两套主题播放状态的音乐表面均没有 `::before`/`::after` 波纹内容和动画。
2. hover 与键盘 `focus-visible` 时图标组合缩放约 1.1，移开或失焦后恢复 1。
3. 暂停斜杠与音符同步缩放，不错位；背景圆形保持 32×32px，命中区保持 44×44px。
4. 减少动态模式下缩放仍可发生，但过渡时长不超过 1ms。
5. 播放/暂停 ARIA、音频状态、双主题和桌面/移动端回归通过。

## 验证

- Playwright 验证无波纹、hover/focus 缩放、失焦恢复、减少动态和尺寸不变。
- 运行 `npm run check`、`npm run build`、`npm run test:e2e`、`npm run check:sdd -- --worktree --base origin/main`。
