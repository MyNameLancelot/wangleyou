# 音乐按钮右上角位置纠正规格

状态：已确认

## 背景

上一变更错误地把用户截图红框理解成“紧邻主题按钮上方”，将音乐按钮放在右下角主题按钮上方约 12px。用户明确指出，红框表示屏幕右上角的位置；音乐按钮只需与右下角主题按钮处于同一条右侧中心线，并与其收起状态大小对齐。

## 目标

- 把首页音乐按钮从右下角工具堆叠移动到屏幕右上角标注位置。
- 让音乐按钮的可见圆形和命中区尺寸分别与主题按钮收起状态一致。
- 保留已确认的播放波纹和暂停斜杠音符。

## 非目标

- 不改变主题按钮的位置、展开行为或主题切换逻辑。
- 不改变背景音乐播放状态、资源、音量、视频阻断或清理逻辑。
- 不合并双主题 UI，不新增依赖。

## 用户确认的设计

1. 音乐按钮固定在屏幕右上角，右侧中心线与右下角主题按钮一致。
2. 音乐按钮命中区为 44×44px，可见毛玻璃圆形为 32×32px，与主题按钮收起状态一致。
3. 按钮距顶部和右侧均使用约 18px 基准，并通过 `env(safe-area-inset-top/right)` 避让安全区。
4. 暂停态继续显示降强调的斜杠音符且无波纹；播放态显示普通音符与扩散波纹。
5. 桌面与移动端均使用相同定位语义，不与内容产生横向溢出。

## 验收条件

1. 海边和草原首页的音乐按钮均位于视口右上区域，44×44px 命中区顶部与右侧偏移为安全区和 18px 中的较大值。
2. 音乐按钮与主题按钮命中区的水平中心误差不超过 2px。
3. 音乐按钮可见圆形为 32×32px，主题按钮收起表面为 32×32px。
4. 桌面 1440×900 与移动端 360×800 均不重叠、不越界、不产生横向滚动。
5. 播放/暂停图标、波纹、ARIA、音频状态和减少动态行为保持上一变更验收结果。

## 验证

- Playwright 分别核对双主题、桌面和移动端的位置、尺寸、右侧中心线与状态视觉。
- 人工核对首页截图，确认音乐按钮位于用户标注的右上区域。
- 运行 `npm run check`、`npm run build`、`npm run test:e2e`、`npm run check:sdd -- --worktree --base origin/main`。
