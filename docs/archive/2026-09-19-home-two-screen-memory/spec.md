# 首页两屏主回忆规格

状态：完成

## 背景

现有首页是可自由滚动的内容列表。用户确认将其改为类似 iPhone 官网的两段整屏体验：滚轮、触控板和键盘操作只在两屏之间切换，页面不在两屏中间停留。

## 目标

- 首页由 Beach/default 主题首屏与“主回忆”两个视口等高模块组成；草原主题保留其自身主题资源。
- Beach/default 主题首屏使用用户确认的 2560×1440 海滩图，主体内容覆盖在可读、立体的毛玻璃卡片上。
- 主回忆从现有相册内容派生一组图片，提供可见的播放进度、暂停/继续、前后翻阅和打开查看器入口。
- 保持移动端、键盘、减少动态效果与资源清理的既有约束。

## 非目标

- 不改变相册配置结构，不新增后端、登录或在线内容管理。
- 不在首页主回忆中实现视频、音频或新的播放队列；视频仍由现有查看器处理。
- 不改变浏览、相册详情与媒体查看器的既有路由和行为。

## 用户确认的交互与视觉要求

1. Beach/default 主题首屏固定使用已确认的俯拍海滩图：海水在上、沙滩留白在下、右侧小船为视觉锚点；草原主题使用其自身主题资源。
2. 首页只有两屏。任一有效向下或向上滚动意图，或首页获得焦点后的上下方向键，只能平滑定位至相邻完整屏；不允许稳定停在中间位置。
3. 第一屏左侧展示站点标题、简短介绍和“开始回忆”主操作；文字后方是可见毛玻璃纹路、半透明、模糊、内外高光与投影组成的立体悬浮卡片，不能只是纯白半透明色块。
4. 第二屏标题为“主回忆”，以照片播放为视觉中心；可暂停/继续、前后翻阅、查看当前索引和进度，并可打开当前照片的既有查看器。
5. 不支持 backdrop-filter 时，文字与按钮仍必须清晰可读；减少动态效果时取消非必要卡片和照片动效，但保留操作反馈。

## 状态与边界

- 首页整屏导航只有 `hero` 与 `memory` 两个逻辑段；非首页路由不受其滚动接管影响。
- 鼠标滚轮与触控板小幅连续输入按阈值合并；段切换动画期间忽略重复切换请求，动画结束后恢复接收输入。
- `PageDown`、`PageUp`、`ArrowDown`、`ArrowUp` 仅在焦点不位于按钮、链接、输入控件或查看器时触发段切换；保留交互控件自身的键盘语义。
- 触屏端用垂直滑动阈值切换整屏，不把普通横向照片浏览手势解释为页面切换。
- 主回忆仅从当前内容中有缩略图或图片资源的照片建立队列；无可用照片时显示明确空状态，不创建计时器。
- 主回忆自动播放仅在该屏处于活动状态、页面可见且用户未暂停时运行；离开第二屏、进入后台、组件卸载或打开查看器时取消计时器。

## 验收条件

- AC-1：桌面 1440×900 首页首次打开时，Beach/default 主题完整显示海滩首屏；下滚或按 ArrowDown 平滑停在第二屏，上滚或按 ArrowUp 返回第一屏，过程中不遗留稳定中间位置。
- AC-2：触控板连续小幅滚动和滚轮连发不会跨越两屏或抖动；减少动态效果下立即切换且无多余动画。
- AC-3：首屏背景在 1920×1080 与 2560×1440 视口无空白边；文本卡片具备可见背景模糊、半透明纹理、高光边缘和悬浮阴影，文字与按钮满足可读性与焦点可见性。
- AC-4：第二屏显示主回忆的当前照片、总数、进度、暂停/继续、上一张、下一张和查看操作；操作能正确更新当前照片。
- AC-5：第二屏播放到末张按既定循环策略停止或回到首张；暂停、离屏、页面隐藏、查看器打开及卸载后不存在残留计时器。
- AC-6：390×844 触屏视口中两屏均完整适配，滑动只在达到垂直阈值时切屏，所有触控目标不小于 44×44px，无意外横向滚动。
- AC-7：首页之外的浏览、相册详情和查看器行为保持既有测试通过。

## 未决默认值

- 主回忆默认从内容排序后的最新 12 张照片组成；若不足 12 张则使用全部可用照片。用户后续可指定固定相册或主题。
- 每张照片默认展示 5 秒，循环开启；用户暂停后不自动恢复。
