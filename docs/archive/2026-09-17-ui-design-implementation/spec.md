# 按设计基线实现前端

## 背景与问题

双主题设计系统已归档（`docs/archive/2026-09-17-long-term-design-system/`，Penpot 为设计事实来源）。运行时仍是单套"暖阳奶油"变量、无视频播放、无主题切换，页面结构与设计稿不一致：设计要求的首页入口区、年份分组浏览、继续播放、查看器控制栏与连续播放都还没有实现。

README 目前把主题切换、视频播放、自动幻灯片列为后续里程碑。本次把其中"主题切换"和"视频播放（含连续播放）"提前落地，并对齐页面与查看器结构。

## 目标

1. **主题运行时**：实现 Default、Beach、Grassland 三套模式，变量语义与 Penpot 语义 Token 一一对应；切换主题保持当前路由、当前媒体、队列位置与播放意图，并记住偏好。
2. **媒体与播放**：播放队列、当前媒体、播放意图、实际播放状态、连续播放开关统一归 `playback`；照片与视频走同一条队列。
3. **页面结构**：首页（影像入口、精选回忆、相册入口、继续浏览/继续播放、主题切换）、影像浏览（年份分组与定位、图片视频混合网格）、相册详情（标题/描述/时间、视频标识、返回路径与相邻内容导航）。
4. **媒体查看器**：单张图片、视频播放、上一项/下一项、播放暂停、连续播放状态、进度、音量、全屏与退出、键盘鼠标触控提示、横竖屏适配、控制栏显示与自动隐藏。
5. **状态覆盖**：首次加载、媒体加载中、空相册、图片加载失败、视频不可播放、配置或内容异常、离线或资源不可用。
6. **响应式与可访问性**：1440 与 390 参考视口、44×44 触控目标、safe-area、可见焦点、对比度、不只依赖颜色、替代文本与字幕说明、reduced-motion 降级。
7. **装饰资产**：海边与草原主题的装饰层按设计接入，可隐藏、可裁切，不遮挡媒体与控制。

## 非目标

- 不引入登录、业务后端、数据库、在线 CMS、付费服务或原生桥接。
- 不做背景音乐与自动幻灯片（设计未覆盖），播放推进只由用户操作或视频自然结束触发。
- 不使用真实家庭影像；演示内容继续使用已标注来源的演示素材。

## 行为规格

### 主题

- 三套模式由 `data-theme` 驱动：`default`、`beach`、`grassland`；缺省与非法值回退 `default`。
- 语义变量命名与 Penpot 一致：颜色 `--color-*`，形状 `--radius-*`，间距 `--space-*`，动效 `--motion-*`，媒体查看器 `--media-viewer-*`。
- 主题切换是纯视觉变化：不改变路由、当前媒体、队列、索引、播放意图或进度；切换后焦点位置不变。
- 偏好写入 `localStorage`（键 `wangleyou.theme`）；读取失败或不可用时静默回退默认主题。
- 非颜色状态必须可见：焦点环 3px 外圈 + 2px 表面色内圈，选中/加载/错误同时有文案或图形。

### 媒体与播放

- 队列元素为 `Media`（照片或视频），由 `openSession(media, id)` 创建，`stepSession` 按索引推进。
- 播放意图（`intent`：`paused`/`playing`）与实际状态分离；视频元素的实际暂停/播放不直接改写意图。
- 视频自然结束（`ended`）时按意图推进：连续播放开启则前进到下一项并继续播放，队列末尾停止。
- 照片没有播放语义，进入照片时意图为 `paused`，控件不显示进度与音量。
- 视频不可播放（解码失败或源缺失）时给出明确提示与重试入口，并提供"下一项"作为退路。

### 页面

- 首页包含：站点标识与主题切换入口、影像入口（跳浏览页）、精选回忆（可点击进入查看器）、相册入口、继续浏览或继续播放（存在上次会话时显示）。
- 浏览页按年份分组，提供年份定位；网格同时渲染照片与视频，视频显示类型标识。
- 相册详情显示标题、描述、时间范围、数量、播放按钮；缩略图网格可打开查看器；提供返回路径与相邻相册导航。
- 路由保持 `#/`、`#/albums/:id`、`#/browse` 三种；未知路由显示未找到状态。

### 查看器

- 顶部：返回/关闭、当前序号与总数、主题切换反馈入口；底部：控制栏。
- 控制栏：播放暂停（视频）、进度（视频）、音量（视频）、连续播放开关、上一项、下一项、全屏、退出。
- 控制栏在无操作 3 秒后自动隐藏；指针移动、触摸、键盘聚焦时立即显示；控制栏隐藏时不改变布局。
- 键盘：`←/→` 切换、`Space` 播放暂停、`M` 静音、`F` 全屏、`Esc` 退出。
- 触控：水平位移超过阈值才切换，垂直手势不拦截页面滚动；所有可点目标不小于 44×44。
- 横屏：媒体优先居中、控制栏贴底；竖屏：媒体完整显示、队列折叠。

### 状态与降级

- 首次加载：相册骨架占位；媒体加载中：占位与 `aria-busy`。
- 空相册：说明与返回入口；图片加载失败：说明 + 重试 + 切换或关闭。
- 视频不可播放：说明 + 重试 + 下一项。
- 内容配置异常：由 `validateContent` 在启动时抛出明确错误，页面显示配置异常说明而不是空白。
- 离线或资源不可用：使用 `navigator.onLine` 与资源错误展示提示条，不阻断已加载内容。
- reduced-motion：位移与视差取消，仅保留即时状态反馈；主题切换改为即时或 ≤1ms。

## 边界与约束

- 主题差异只允许出现在 Token 值、装饰 Slot、背景层、动效节奏；组件结构与控件位置两套主题完全一致。
- 业务组件不得引用主题专属原始色，不得维护主题条件分支。
- 演示内容必须在界面标注；不得把真实家庭数据写进代码或设计稿。
- 未确认的交互语义不得静默扩张范围：出现新语义先更新本规格与 Penpot。

## 验收条件

- B1：三套主题可由 `data-theme` 切换，`localStorage` 记住偏好，非法值回退默认。
- B2：主题切换保持路由、当前媒体、队列索引、播放意图与进度；切换后焦点不丢失。
- B3：照片与视频共用一条队列，上一项/下一项与索引显示正确。
- B4：视频自然结束后按连续播放开关推进或停止。
- B5：查看器支持播放暂停、进度、音量、全屏、退出，并提供键盘与触控操作提示。
- B6：控制栏在无操作后自动隐藏，指针/触摸/键盘聚焦时恢复，不改变布局。
- B7：首页、浏览页、相册详情、未找到页按设计结构渲染，浏览页按年份分组并提供定位。
- B8：加载中、空相册、图片失败、视频不可播放、配置异常与离线提示均有可见且可访问的状态。
- B9：1440 与 390 视口下无横向溢出，触控目标不小于 44×44，safe-area 生效。
- B10：键盘可完成打开、切换、播放暂停、全屏与退出；焦点可见且顺序合理。
- B11：`prefers-reduced-motion: reduce` 下取消位移动效，主题切换与查看器开关即时完成。
- B12：演示内容与素材来源在界面上有标注，未使用真实家庭影像。
