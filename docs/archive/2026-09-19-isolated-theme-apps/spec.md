# 全站隔离主题应用规格

状态：完成

## 目标

海边与草原分别渲染完整站点 UI；主题间不共享 React UI、CSS、装饰或资产。两者通过同一份无 UI 契约保持路由、查看器、相册和首页两屏行为一致。

## 验收

1. 静态检查拒绝任一主题导入另一主题或共享 React UI。
2. 海边和草原分别拥有导航、首页、相册与查看器；主题切换保持路由和查看器会话。
3. 两主题首页均只能在 hero 与主回忆两个完整视口间落点切换，主回忆控制语义一致。
4. 海边仅在自身主题目录使用 `react-liquid-glass-svg`；增强不可用时仍可读、可聚焦、可操作。
5. 双主题均通过单元测试、构建与桌面/移动端浏览器流程验证。
