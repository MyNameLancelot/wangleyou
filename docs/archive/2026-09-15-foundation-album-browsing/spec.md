# 工程初始化与相册浏览闭环

状态：已完成并验证。范围：首个可运行里程碑，完整产品需求仍然有效。

依据：[需求基线](../../requirements.md)、[总架构](../../architecture.md)、[开发指导](../../../AGENTS.md)。

## 目标与非目标

交付首页 → 相册 → 照片大图 → 切换 → 返回的真实浏览流程，具有默认主题、响应式布局、配置校验及静态子路径兼容。

本次不实现自动幻灯片、视频播放、背景音乐、主题切换、原生能力或线上发布，不创建无效按钮或空播放器。后续里程碑继续实现这些完整需求。

## 方案比较与推荐

1. 推荐 React + TypeScript + Vite：组件边界清晰，适合后续媒体状态与交互演进；成本是框架运行时及构建依赖。
2. 备选 Vite + 原生 TypeScript：运行时依赖更少，但需要自行管理 DOM 更新、组件生命周期与复杂状态同步。

推荐 npm、CSS Modules 和 CSS 设计变量，不引入全局状态库或组件库。使用原生 Hash 导航（首页 `#/`、相册 `#/albums/<id>`），由 app 解析和订阅；未知路径与相册显示返回入口，地址解析错误不崩溃。依赖具体版本在初始化时核实并写入锁文件和决策记录。环境已检测到 Node 24.18.0、npm 11.16.0。

Vite 构建 base 通过配置指定，默认仓库路径 `/wangleyou/`，支持 `/` 和任意测试子路径。所有发布资源使用统一 URL 解析，不硬编码站点根路径。Hash 内路径刷新无需服务器重写。

参考：[React 官方起步](https://react.dev/learn/build-a-react-app-from-scratch)、[Vite 静态部署](https://vite.dev/guide/static-deploy)。

## 页面与视觉

网站暂名“王乐游 · 成长相册”，作为可配置文案。默认暖阳奶油主题：米白背景、深棕正文、柔和橙色强调，留白与照片占主要空间，系统中文字体避免外部字体依赖。

首页使用简洁顶栏、适度大小的精选照片区、相册卡片和近期照片入口；展示演示素材标记。桌面形成宽松多列，移动端缩为单列或双列，不使用仅悬停可见的关键操作。

相册页包含返回入口、标题、日期、描述和缩略图网格。大图查看器采用深色背景、清晰的关闭和切换控件，图片 contain 保留原比例，显示当前位置与说明。深色查看背景为默认主题的媒体呈现设计，不是第二套主题。

不需要先提供真实家庭照片。演示图片以自然、旅行或生活静物为主，下载到仓库并记录来源和授权条件，不使用随机外链作为验收素材。

## 模块与数据流

- app：应用装配、Hash 导航、页面切换和全局基础样式。
- content：读取、校验、排序、公开类型及资源 URL 解析。
- albums：首页与相册呈现，通过回调请求打开照片。
- playback：本次仅实现照片队列、当前索引、打开/关闭及边界切换；不创建计时器或音频控制。
- media-viewer：媒体呈现、加载/错误反馈、键盘、手势、焦点和全屏能力。
- themes：默认主题设计变量；不实现偏好或切换业务。
- shared：仅在确有跨模块复用需求时创建。

依赖遵循总架构。查看器可以有当前图片加载状态，但不能重复维护当前媒体业务索引；旧请求和事件不得覆盖新媒体状态。

## 内容格式与资源维护

使用静态 JSON 配置，包含站点文案、相册数组、相册 ID/标题/可选日期和描述、媒体列表。媒体以 photo/video 区分类型，包含 ID、src、可选 thumbnail/poster、日期、说明、alt、宽高；本次演示与交互只使用照片。若添加 video 配置，列表明确显示本阶段尚不支持播放，不创建假播放器。

相册 ID 全局唯一，媒体 ID 相册内唯一。日期使用 YYYY-MM-DD 并验证真实日期；排序与回退规则遵循需求基线。ID 限定小写字母、数字和连字符，避免地址歧义。资源地址限制为发布目录内相对路径，不允许上级目录跳转。

计划路径：配置 `src/content/albums.json`，发布图片 `public/media/`，缩略图 `public/media/thumbs/`。相机源素材由维护者在仓库外保存；仓库中的发布大图是准备后用于浏览的文件。提供本地缩略图脚本，从发布大图生成派生缩略图，不覆盖大图；派生文件提交 Git，构建只校验，不修改素材。具体尺寸、格式和图片处理依赖写入实施计划。

演示至少两个非空相册，合计至少六张横竖照片；测试覆盖空相册和单张相册。内容校验失败阻断构建，报告配置位置；运行时图片失败显示重试和返回，不影响整个页面。

## 浏览交互与生命周期

打开所点照片，默认手动浏览；首尾切换按钮禁用，不循环。支持方向键、Esc、左右滑动，垂直手势不触发切换。原生 dialog 或等效可访问实现约束焦点，关闭恢复触发元素焦点；触发元素已移除时回退到页面合理入口。

打开查看器锁定背景滚动，关闭恢复；路由切换关闭查看器并释放监听。加载中显示明确状态，快速切换通过媒体身份隔离旧事件；仅按需加载大图，可预加载相邻一张。全屏能力不可用时仍保留完整页面内查看。
