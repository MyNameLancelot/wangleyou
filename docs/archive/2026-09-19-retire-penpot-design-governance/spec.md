# 废弃 Penpot 设计治理规格

状态：完成

## 背景

当前仓库把 Penpot 作为视觉与交互设计基线，并要求 `change.json` 声明设计影响。用户明确要求全面废弃该流程，改为直接口述交互设计。

## 目标

- 移除现行规则、产品基线、架构、README、活动变更模板和 SDD 校验中对 Penpot 与设计影响分级的要求。
- 保留 full/light、行为与架构影响、验证证据、模块边界和运行时设计变量等工程治理。
- 让未来用户可见交互以用户口述、活动规格和浏览器验证为唯一工作流。

## 非目标

- 不删除历史归档或历史视觉资产；它们仅保留为历史记录，不再约束实现。
- 不改变现有页面、主题、媒体或播放行为。
- 不删除运行时主题 Token、组件复用、无障碍或响应式约束。

## 用户确认的交互要求

后续交互设计由用户口述确认；不要求创建、更新、审查或核对 Penpot 页面、组件、原型或版本。

## 验收条件

- AC-1：现行 AGENTS、需求、架构、README、SDD 指南和活动变更规范不再要求 Penpot 或设计影响分级。
- AC-2：`scripts/sdd/check.ts` 不再要求或校验 `designImpact`、`designReason`，其测试覆盖仍通过。
- AC-3：活动 change.json 不再使用已废弃字段；本次完整变更记录包含规格、计划、任务和真实验证证据。
- AC-4：ADR 0003 记录替代决定，ADR 0002 明确标为已被替代。
- AC-5：`npm run check:sdd -- --worktree --base origin/main`、`npm run check` 与 `npm run build` 通过。
