# 紧凑主题切换规格

状态：完成

## 目标

将两个主题的右下角开关改为默认只有循环图标、毛玻璃圆形仅包住图标，hover/focus 展开为“循环图标 + 主题切换”的胶囊，并删除首页演示统计文案。

## 用户确认的口述要求

- 循环图标不手画，改用 `lucide-react` 的现成循环图标。
- 默认状态只有循环图标，毛玻璃背景只有图标那么大。
- 悬浮展开为胶囊：左边循环图标、右边“主题切换”文字。
- 点击胶囊执行主题切换。
- 首页不再显示“7 个片刻 · 3 本相册 · 内容均为演示”。

## 第三方依赖评估

| 项目 | 结论 |
| --- | --- |
| 包 | `lucide-react` 1.47.0（图标） |
| 许可 | ISC |
| 运行时依赖 | 无额外运行时依赖；peer 支持 React 16.5–19 |
| 体积 | 按需引入单个图标；生产构建 JS 由 292.32 kB 增至 295.41 kB（gzip 84.48 kB → 85.87 kB） |
| 浏览器回退 | 图标为内联 SVG 描边，不依赖图标字体、网络请求或 JS 特性；玻璃增强不可用时按钮降级为不透明底色 |
| 无障碍影响 | 图标 `aria-hidden`，按钮保留 `aria-label="切换主题，当前是…主题"` 与 44×44px 命中区域；不新增键盘或读屏陷阱 |

结论：采用既有轻量库图标，删除此前手写的双箭头 SVG。

## 非目标

- 不改变主题持久化、路由、首页两屏、主回忆或查看器行为。
- 不共享两套主题的 UI 或 CSS。

## 验收条件

1. 两主题默认只显示循环图标，毛玻璃圆形紧贴图标（20px 图标、32px 圆形），按钮命中区域至少 44×44px。
2. 桌面 hover 与键盘 focus 时展开为约 142px 的胶囊，图标右侧显示“主题切换”。
3. 点击仍能切换主题并保持既有上下文和偏好。
4. 两主题首页不再渲染“7 个片刻 · 3 本相册 · 内容均为演示”或对应占位。
5. 桌面和移动端无横向溢出，焦点清晰，减少动态偏好生效。
