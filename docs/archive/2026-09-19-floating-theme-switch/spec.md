# 悬浮主题切换规格

状态：完成

## 目标

移除海边与草原主题的全局顶部导航，让首页首屏图片从视口顶部完整呈现；每个主题独立提供右下角毛玻璃主题切换按钮。

## 非目标

- 不改变首页两屏吸附、主回忆、路由或查看器行为。
- 不恢复共享主题 UI、CSS 或资产。
- 不新增导航抽屉或新的业务页面。

## 已确认交互

- 顶部品牌、首页、全部影像、相册和原主题按钮整条顶栏均不显示。
- 右下角按钮默认仅显示主题图标，背景具有毛玻璃质感和悬浮层次。
- 鼠标悬浮或键盘聚焦时显示“主题切换”，点击后切换主题。
- 移动端无悬浮能力时仍以可访问名称和不小于 44px 的触控目标提供同一操作。

## 验收条件

1. 两套主题及所有路由均不渲染全局顶部导航。
2. 两套主题分别拥有独立的右下角毛玻璃主题切换实现，主题之间无 UI/CSS 导入。
3. 控件默认为图标，悬浮与键盘聚焦时显示“主题切换”，点击后主题偏好和当前上下文按原规则保持。
4. 控件在桌面与移动端不产生横向溢出，触控目标不小于 44px，键盘焦点清晰可见。
5. 首页两屏、路由、查看器和现有双主题行为回归通过。
