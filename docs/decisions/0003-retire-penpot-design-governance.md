# 0003：废弃外部设计稿与设计影响门禁

日期：2026-09-19  
状态：采纳

## 背景

此前 [0002](0002-design-system-governance.md) 将 Penpot 和 `designImpact` 分级纳入开发流程。用户现明确要求全面废弃该外部设计稿流程，页面与交互设计改由用户口述确认。

## 决定

不再维护 Penpot 或其他外部设计稿，也不再把它们作为视觉、交互、组件状态或响应式的事实来源。`change.json` 不再包含 `designImpact`、`designReason`，SDD 校验不再要求或校验这些字段。

新增或改变用户可见页面、流程、交互语义、组件语义、主题、重要响应式、空状态或错误恢复时，仍必须采用 full 流程。实施前，开发者将用户已确认的口述要求写入 spec.md 的行为描述和可编号验收项；实施后，以运行时浏览器在指定视口和流程验证结果。

运行时的语义 Token、主题模式、组件复用、无障碍和响应式工程约束继续保留。这些约束由产品需求、架构、模块文档和测试维护，不依赖外部设计工具。

## 影响

- 更新 AGENTS、需求、架构、README、SDD 指南和活动变更规范，移除 Penpot 责任与设计影响分级。
- 简化 SDD 检查脚本和测试，保留 full/light、行为/架构影响、验证证据、影响文档与模块依赖校验。
- 历史归档和历史设计资产只作为当时事实或视觉回顾保留，不再约束后续实现。
