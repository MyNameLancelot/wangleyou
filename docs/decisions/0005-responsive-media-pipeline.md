# ADR 0005：构建期派生 WebP 与相册详情瀑布流

日期：2026-09-23
状态：已接受

## 背景

相册原图此前直接放在发布目录 `public/media/photos/` 随站点发布：单张 1600px JPEG 体积偏大，移动端首屏流量高；相册详情用固定框多栏排布，横竖图被裁切，也无法按屏幕选择合适尺寸。用户要求仓库保留原图，但网页只加载构建期生成的多尺寸 WebP，并且未变化的图片在本地与 CI 都不重复编码。

## 决策

1. 原图、相册 `meta.json` 与 `home-memory.json` 存放在仓库 `media-source/<相册目录>/`，照片、视频与视频封面源素材共用同一层结构，不设 `photos` 或 `video` 中间层；源素材提交 Git 但不发布。
2. 构建期按内容哈希与配置版本增量生成 480/960/1600/2560 宽度 WebP（不放大、清 EXIF、保持比例）到 `public/media/<相册目录>/`，文件名带内容哈希；未变化的图片命中 `.cache/media-variants/` 不重新编码，本地与 GitHub Actions 使用同一缓存键策略。视频封面源素材 `<视频同名>.poster.jpg` 走同一条派生与缓存路径，索引里写入 `poster`、`posterSrcSet` 与取自封面的 `width`/`height`；**没有提供封面源素材时，构建期渲染一张中立占位封面**（16:9、深色底纹、版本化的 `video-poster-placeholder-v1`），因此视频始终有可用封面，构建不因缺封面失败。
3. 相册详情使用 `react-photo-album@3.6.1` 的 `MasonryPhotoAlbum`，列数、间距与 `sizes` 采用库默认响应式档位（容器 ≥1200px 五列/20px，600–1199px 四列/15px，300–599px 三列/10px，<300px 两列/5px）；每张照片加白色相纸相框（8px 留白、8px 圆角、主题色轻投影），留白由组件 `padding` 计入列宽。
4. 交互样式约束：按钮在任何状态下都不使用边框；聚焦环只在键盘导航时出现；次要按钮悬浮与按下不改变底色或文字色。
5. 视频只发布 H.264 + AAC 的 MP4（faststart）：构建期按内容哈希复制 `<文件名>.<哈希12>.mp4` 到相册目录，目标存在即跳过复制，不做转码、不抽帧、不依赖 ffmpeg/ffprobe；只接受 `.mp4`，>100 MB 警告、>200 MB 构建失败，源→产物映射记录在缓存清单里用于清理旧文件。

## 备选方案

- 保留原图直发、只靠浏览器懒加载：实现最省，但移动端仍要下载 1600px 原图，也无法按屏幕选择尺寸。
- 图片 CDN 或运行时转码：需要外部服务或后端，超出“纯静态家庭影像站”的既有边界。
- 自研 CSS 多栏瀑布流：省一个依赖，但要自行处理列高平衡、响应式列数、`srcSet`/`sizes`，长期维护成本高于收益。
- 用 `border` 实现相框：会改变尺寸计算并违反既有的“缩略图无描边”规则，因此改用 `padding` + 背景 + 投影。
- 构建期用 ffmpeg 或 WASM ffmpeg 自动抽帧生成封面：让 CI 引入数百 MB 原生依赖或约 25 MB 的额外运行时依赖，超出“纯静态站、构建期只用 Node”的边界；改为维护者按需离线提供源图，缺失时用 sharp 渲染中立占位封面（不需要视频解码）。
- 构建期转码视频：同样需要原生依赖与不可控的构建时长，且转码失败会让发布流水线变复杂；改为约定离线转码形态，构建期只做容器与体积校验。

## 取舍

- 仓库保留原图会增大克隆体积，换来可随时重新派生与可追溯的素材来源。
- 派生 WebP 不提交 Git，必须在构建流程内生成：CI 需要恢复缓存，否则每次构建都重新编码全部图片。
- 采用库默认档位意味着桌面为五列、单张约 224px，比自定三列更密；换取与官方示例一致的观感与更少的自定义代码。
- 派生输出布局属于缓存语义的一部分：布局变化必须提升生成器配置版本（现为 `webp-q80-effort4-v2`），否则会复用清单里的旧路径。
- 视频入库前必须离线转码：维护者多一步手工操作，换来构建、CI 与运行时的零转码依赖；体积超限在构建期失败而不是线上才发现。
- 占位封面只是兜底：它统一 16:9，不能反映真实画幅；想要准确比例与真实画面时仍需提供 `<视频同名>.poster.jpg`（视频缩略图的播放标识由页面叠加，占位封面不烘焙角标）。

## 影响模块

`scripts`（派生与缓存）、`content`（尺寸与 `srcSet` 契约、索引）、`themes`（瀑布流、相框与交互样式）、workflows（媒体缓存）、docs（需求、架构、README 与素材说明）。
