# 0006：全站共用的 lightbox 查看器

日期：2026-09-23。状态：采纳。

## 背景与决定

两套手写查看器曾重复实现手势、媒体控制、焦点和全屏，维护成本高且行为容易漂移。采用 `yet-another-react-lightbox` 与官方插件，集中在 `src/media-viewer`；当前唯一 book 主题仅挂载它，不能覆盖样式/功能或复制实现。

启用 Captions、Fullscreen、Slideshow、Thumbnails、Video、Zoom，默认样式与媒体控制交给库。显式保留非循环、背景点击关闭、手动启动幻灯片，并按已确认行为裁剪工具栏/导航，提供寄语定位、缩略图收起条及全屏样式。界面契约以 [需求](../requirements.md) 和 [模块说明](../../src/media-viewer/module.md) 为准，不把“库默认”当成取消这些约束的理由。

App 持有 playback Session 实例；查看器受控消费 open/index，通过 `view` 和 video 事件发命令，不保存第二份业务索引。video ended 不推进，播放失败回报附发起队列/索引以拒绝迟到结果。关闭/改路由/卸载时释放监听和媒体，恢复滚动与触发焦点；主题不参与查看器 DOM 生命周期。

## 候选与取舍

- 继续手写查看器：外观完全可控，但需长期维护手势、无障碍、媒体和浏览器差异；选择成熟库降低维护面。
- 每个主题各写包装和样式：可独立设计，但违反用户要求的共用查看器，并重复维护；集中在单一模块。
- 额外焦点陷阱库：库已提供 inert 模态隔离，只需把 Tab 在边界回绕，避免焦点进入浏览器 chrome 后 Esc/方向键失效；复用平台监听，不增加依赖。

共用模块使主题失去查看器外观自主权，换取一致行为与单点维护。升级库时须核对插件、DOM/CSS 类名、媒体事件、焦点和全屏；这些外部契约由查看器及其测试承担，主题不能引用 `.yarl__*` 定制样式。支持范围以实际浏览器/WebView 能力为准，库不能替代设备验证。

## 影响与验证

影响 media-viewer 的 DOM/事件、playback 命令、app 装配与 themes 挂载。视频播放角标属于详情页 UI，不烘焙进媒体封面；封面和视频发布由 [0005](0005-responsive-media-pipeline.md) 负责。

验证打开定位、完整比例、寄语、手动/幻灯片切换、视频结束、背景关闭、Tab 回绕/焦点回归、全屏降级、迟到播放失败及卸载清理。依赖版本由锁文件维护，不保留旧构建体积作为当前指标。
