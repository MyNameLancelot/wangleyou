## 目标与边界

保护源素材及最后有效发布索引，恢复后台暂停、影像内寄语和首页一键恢复，修正检查规则、双 base 验收、图片传输及工具读取，删确定无用残留并同步真实契约。保留现有文档整理；不升级依赖、增加桥接或恢复音乐。用户后续已授权 v1.0.11 测试 APK 交付，并在真机反馈通过后授权提交、推送和创建 PR；未授权合并或部署网站。

复用 sharp、lightbox 插件 ref、原有响应式候选和 Node 文件/流 API；不新增依赖。文件生成采用局部扫描/派生/提交职责分离，避免通用事务框架。查看器 DOM 副作用可以内部 hook 拆分，Session 继续由 playback 纯函数管理。

## 行为与验收

- AC1：逐项拒绝输出 symlink 及祖先逃逸；编码到同目录唯一临时文件后替换，hardlink 不改写源 inode。失败保留已有输出，只清理本项临时文件；dry-run 不写，源指纹不变，CLI/退出码不变。
- AC2：小于 480px 的照片和封面以源宽生成至少一个候选，不放大；像素舍入只容许比例对应的至多一像素偏差。损坏缓存重新派生，非法缓存路径不得参与删除。
- AC3：扫描不提前覆盖发布索引；派生、校验及暂存成功后提交索引/缓存，提交失败恢复先前有效文件。旧产物只在成功提交后清理；失败仅回收本轮新建的发布文件，不删除先前存在的产物，源素材只读。
- AC4：MP4 扩展名关联忽略大小写，stem 保持大小写；同视频多个封面或同 stem 多视频明确报错，孤立封面仍报错。此处采用行动清单建议的拒绝歧义规则。
- AC5：hidden 停止视频和幻灯片，回来不自动恢复；隐藏挂载、迟到播放结果、切换和关闭不会重播或回写旧状态。合成可见性测试与真实后台结果分开记录。
- AC5a：portal 挂载超过 5 秒或当前媒体 DOM 被替换后仍建立有效绑定；被替换元素及其迟到 play 回调不能改写当前会话，关闭后观察器和监听清理。
- AC5b：Android 主框架加载或失败时隐藏底层 WebView，使 TalkBack 只访问当前原生加载/错误界面；成功后再显示网页。断网提示与“重新连接”可主动阅读和操作；不增加桥接或改变导航白名单；安装包交付由独立测试包记录覆盖。
- AC6：寄语在实际影像范围内，窄竖图与 390×300 短视口无溢出，缩略图/全屏/缩放后重新定位；首页后台恢复按钮一次点击继续，独立用户暂停保留；末页不创建自动 live 播报。
- AC7：主题隔离适用于 book 和未来主题；首页 E2E 不写死 base；两种 base 独立构建并通过全部适用浏览器用例。
- AC8：首页和索引复用 srcSet/sizes；卷页不额外请求最大图；头图保持像素/透明背景与裁切一致再替换。冷上下文记录不同宽度和 DPR 资源选择。
- AC9：验收服务器 HEAD 不读取 body，Range 仅流式读取所需区段，保留 HTTP/realpath 契约；断开清理流，100MiB 合成文件验证不分配整文件 Buffer。
- AC10：只删全仓确认无调用的旧能力/样式，必要基线和模块文档反映实际实现；check/build/SDD/差异检查通过，未验证设备范围保持真实。
