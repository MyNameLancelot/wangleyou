# 实施计划

对应 [spec.md](spec.md)。

1. 在 content 模块以测试驱动方式加入 `mediaUrl()`，复用严格路径校验和编码逻辑；保留 `assetUrl()` 兼容 API。（AC-1、AC-2、AC-4）
2. 将两主题页面、查看器、音乐组件和媒体预加载的全部媒体引用迁移到 `mediaUrl()`；用静态搜索核对不存在主题私自拼接的 CDN/媒体地址。（AC-3）
3. 使用默认构建及带 jsDelivr 前缀的构建验证产物，运行检查和桌面/移动浏览器回归；确认路由与页面 base 不变。（AC-1、AC-2、AC-5）
4. 同步需求、架构、模块文档和 README，填写验证记录与任务状态；验收完整后归档整个变更目录。（AC-5）

回退：移除 `mediaUrl()` 消费迁移并恢复以 `BASE_URL` 默认的调用；内容 JSON、页面 base、路由和发布工作流不需回退。
