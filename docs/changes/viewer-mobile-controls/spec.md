# 查看器移动端控件修复

## 问题与范围
用户 Android 安装包截图中，右上角全屏按钮与系统状态栏重叠；底部缩略图不能横滑。修复共用 media-viewer 与 Android 容器，不改首页、媒体资源、业务队列或原生桥接。

## 行为与验收
- AC1：Android 容器使用系统栏/开孔真实 inset 为网页预留顶部空间，旋转及退出视频全屏后重新应用；不依赖 WebView 是否支持 CSS env。
- AC2：浏览器查看器工具栏避开顶部及侧边 CSS 安全区，缩略图避开底部；按钮保留至少 44px 命中区，桌面布局不额外下移。
- AC3：缩略图触屏左滑切下一项、右滑切上一项，每次手势至多切一项，首尾不循环；点击继续直接选择，拖动后不误触缩略图。
- AC4：短距离移动、纵向移动、多指和取消手势不切项；收起、重新展开、退出后重开仍可用，卸载清除事件。
- AC5：既有媒体横滑、缩放、字幕、全屏和键盘操作不受影响。浏览器模拟和原生设备验证分别记录。

## 方案选择
已检查现有 Thumbnails 插件：只消费点击/键盘与主画面切换事件，没有触屏横滑。复用官方 ControllerRef 的 next/prev 和 Pointer Events，增加小型事件适配，不新增依赖、不维护第二份索引、不把虚拟轨道改成独立滚动列表。CSS env 负责浏览器安全区；Android 在原生侧消费顶部 inset，避免旧 WebView 返回零造成不可点击。原生开屏保持满屏，网页采用顶部 margin，不改媒体播放全屏策略。
