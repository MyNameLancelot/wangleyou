# 家庭原生 App 规格

## 问题与目标

家人需要独立安装的 iPhone、iPad 与 Android App。安装包只含原生壳、图标和少量故障界面资源；网站 HTML/JS/CSS、相册配置与媒体由现有线上地址加载，仍由 main 的 Pages/CDN 发布。网站继续独立运行。

## 非目标与边界

不提供 PWA、商店上架、登录、业务后端、离线媒体库、原生桥接、自动随 main 更新打包或公开发布安装包。不改变媒体 URL 规则。原生容器只允许 `https://mynamelancelot.github.io/wangleyou/` 子路径成为顶层站内页面；其他 HTTPS 链接经用户操作交由系统浏览器，非 HTTPS 可执行/自定义 scheme 拒绝。媒体子资源仍由页面按既有规则请求。

## 验收条件

- A1：原生 iOS universal App 可在 iPhone/iPad 安装，Android 输出 APK；默认访问上述经部署配置核实的 HTTPS 地址，无媒体或网站构建产物入包。
- A2：安全区域、旋转及平板尺寸可用；站内 Hash 导航不离开 WebView，Android 系统返回优先关闭查看器/返回站内历史，iOS 使用系统 WebView 的返回手势。
- A3：外部 HTTPS 顶层链接只在用户触发时由系统浏览器打开；危险 scheme、非站内顶层导航与新窗口不在 WebView 加载。
- A4：初次与后续主框架加载有进度状态；断网或站点不可用显示可理解的错误与重试入口；恢复网络后可重新加载。
- A5：照片查看、MP4 播放与系统可用的全屏能力不因容器限制被主动关闭；页面已有查看器和播放状态仍唯一归网站持有。
- A6：Android 只要求 INTERNET 权限，禁用明文流量；iOS 不放宽 ATS。原生壳不注册 JS 桥接。
- A7：网站 CI/部署与原生安装包构建分离；后者仅手动触发，产物不公开发布，签名资料和设备 ID 不进仓库。
- A8：记录可复现命令、签名与设备登记步骤，核实可执行检查，模拟器与真机结果分开。

## 未决的外部条件

Apple Developer Program、iOS 签名证书/描述文件、已登记设备，以及本机完整 Xcode/Android SDK 属于打包和真机验收的外部条件。无这些条件时不得把 IPA 或设备验收标成完成。
