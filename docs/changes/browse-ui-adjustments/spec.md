# 留影页界面调整

## 问题

`#/browse` 页面当前以“全部影像”为标题，并展示媒体数量、年份数量和相册快捷列表；宽视口下浏览主体没有任何容器内缩，左侧定位栏贴在窗口边缘，与 hero 文案、筛选胶囊不在同一条内容边上，“最新优先”被推到网格最右侧，底部还有一段键盘提示文案。

## 目标

- 页面标题由“全部影像”改为“留影”，副标题与 hero 结构保持。
- 保留“全部 / 照片 / 视频”类型筛选和按年份定位操作，但不展示任何统计数量。
- 左侧定位栏只保留“光阴刻度”与年份按钮，移除“相册”区与相册快捷链接。
- 浏览主体与 hero 共享同一内容边距和最大宽度，宽视口下定位栏、网格和年份标题都落在稳定的内容范围内。
- 年份标题旁不再显示“最新优先”等排序说明。
- 正文改为按年份分组列出**相册**：每个相册一张卡（沿用影像卡样式），说明条显示相册名与相册说明，点击进入相册详情；同一年内按 `YYYY-MM` 月份与 `sequenceNN` 顺序排列。
- 留影页的相册卡使用最多三张照片的错位层叠封面，明确传达“相册”而非单张照片；直接采用构建期生成的媒体顺序取前三个可用缩略图，因此 `topNN`（如 `top00`、`top01`）按既有构建期排序优先位于最前层。
- 构建期是相册照片展示顺序的唯一来源：`generate-photo-index` 先按 `topNN` 编号升序，再按文件名自然序生成 `album.media`；主题运行时不重新解析文件名或排序。
- 每个相册在该展示顺序中的前三张发布图片均为 3:2；层叠封面以 `cover` 铺满各自可见框，不露出底色、白色描边或下方投影。后两层只从右上方露出；小视口保留三层但缩小错位距离，不引入横向溢出。
- 留影页相册卡鼠标悬浮时不放大或聚焦封面图片。
- 光阴刻度的年份按钮悬停时使用与类型筛选选中项相同的主题主色背景和前景文字色。
- 缩略图不再显示“演示素材”角标，说明条改为更矮的紧凑单行。
- 海边主题移除页面背景的浅色圆形装饰层。
- 删除底部的键盘提示文案。

## 非目标

- 不移除类型筛选或年份定位。
- 不改动首页、相册索引页、相册详情页的文案与元数据显示。
- 不新增排序交互；移除既有“最新优先”只读说明。
- 不改动 Hash 路由、媒体 URL 解析、主题隔离和部署路径。

## 行为与边界

- 两个主题（海边、草原）的留影页保持同一信息层级；主题各自维护 JSX 与 CSS，不共享组件或样式类。
- 层叠封面的取图与渲染规则在两个主题中保持一致：直接使用构建期确定的相册媒体顺序，前层是第一个可用缩略图，后两层按该顺序补足且不重复；相册少于三张时只渲染可用层数，空相册沿用既有空封面。
- 三层封面仅改变相册卡的预览裁切；相册详情和其他媒体展示仍按既有规则完整显示、不裁切。
- 筛选只影响列表与年份分组，不改变路由、滚动容器或查看器入口。
- 移动端（≤900px）仍隐藏左侧定位栏、显示年份快捷导航，并可用年份按钮滚动定位。
- 360px 移动端不出现横向溢出，交互目标不小于 44×44px。

## 验收条件

1. 两个主题的留影页一级标题为“留影”，不再出现“全部影像”作为该页标题。
2. 筛选胶囊只显示“全部 / 照片 / 视频”，页面任意位置不出现媒体数量、年份数量等统计数字。
3. 左侧定位栏只包含“光阴刻度”和年份按钮，没有“相册”区或相册快捷链接。
4. 桌面宽视口（≥1440px）下，左侧定位栏左边缘与留影页 hero 标题左边缘对齐，差值不超过 1px；网格不贴窗口右边缘。
5. 页面不出现“最新优先”等排序说明；每个相册一张卡，说明条显示相册名与相册说明。
6. 2025 年只有“周岁”一张卡；2024 年是“破壳”“百日”两张卡，破壳在前。
7. 卡片不出现“演示素材”角标，说明条高度不超过 40px（桌面端）。
8. 页面不再渲染底部键盘提示文案。
9. 360px 视口下页面无横向溢出，年份快捷导航可用，相册卡片可进入相册详情。
10. 海边主题不再渲染背景装饰层，草原主题的装饰层保持 `aria-hidden` 且不拦截指针。
11. Hash 路由、媒体 URL、主题切换与查看器行为不变。
12. 两个主题中，留影页每张有三张可用图片的相册卡都渲染三层封面；最前层图片为 `topNN`，后层向右上错位且不带白色描边或投影，360px 视口不产生横向溢出。
13. 生成索引中每个相册的 `media` 顺序为 `topNN` 编号升序后接其余文件名自然序；留影页按该顺序取前三张，不额外排序。
14. 每个相册展示顺序的前三张发布图片为 3:2，层叠封面图片使用 `object-fit: cover`，不露出卡片底色；相册详情图片仍完整显示。
15. 桌面端光阴刻度年份按钮 hover 的背景色与“全部 / 照片 / 视频”当前选中项一致，文本使用相同的选中态前景色。
16. 两个主题中，留影页相册卡 hover 后封面图片不发生缩放或其他 transform。

## 实现说明

留影页是用户可见的浏览页布局与信息层级变化，因此按 full 记录本变更；两个主题各改自己的 `ThemePages.tsx` 与 `ThemePages.module.css`，不引入共享 UI 组件或新依赖。
