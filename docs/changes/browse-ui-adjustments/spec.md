# 留影页界面调整

## 问题

`#/browse` 页面当前以“全部影像”为标题，并展示媒体数量、年份数量和相册快捷列表；宽视口下浏览主体没有任何容器内缩，左侧定位栏贴在窗口边缘，与 hero 文案、筛选胶囊不在同一条内容边上，“最新优先”被推到网格最右侧，底部还有一段键盘提示文案。

## 目标

- 页面标题由“全部影像”改为“留影”，副标题与 hero 结构保持。
- 保留“全部 / 照片 / 视频”类型筛选和按年份定位操作，但不展示任何统计数量。
- 左侧定位栏只保留“光阴刻度”与年份按钮，移除“相册”区与相册快捷链接。
- 浏览主体与 hero 共享同一内容边距和最大宽度，宽视口下定位栏、网格和年份标题都落在稳定的内容范围内。
- 年份标题旁不再显示“最新优先”等排序说明。
- 缩略图说明条显示所属相册名称，跨相册浏览时能看出影像出处。
- 删除底部的键盘提示文案。

## 非目标

- 不移除类型筛选或年份定位。
- 不改动首页、相册索引页、相册详情页的文案与元数据显示。
- 不新增排序交互；“最新优先”仍是只读说明。
- 不改动 Hash 路由、媒体 URL 解析、主题隔离和部署路径。

## 行为与边界

- 两个主题（海边、草原）的留影页保持同一信息层级；主题各自维护 JSX 与 CSS，不共享组件或样式类。
- 筛选只影响列表与年份分组，不改变路由、滚动容器或查看器入口。
- 移动端（≤900px）仍隐藏左侧定位栏、显示年份快捷导航，并可用年份按钮滚动定位。
- 360px 移动端不出现横向溢出，交互目标不小于 44×44px。

## 验收条件

1. 两个主题的留影页一级标题为“留影”，不再出现“全部影像”作为该页标题。
2. 筛选胶囊只显示“全部 / 照片 / 视频”，页面任意位置不出现媒体数量、年份数量等统计数字。
3. 左侧定位栏只包含“光阴刻度”和年份按钮，没有“相册”区或相册快捷链接。
4. 桌面宽视口（≥1440px）下，左侧定位栏左边缘与留影页 hero 标题左边缘对齐，差值不超过 1px；网格不贴窗口右边缘。
5. 页面不出现“最新优先”等排序说明；每张缩略图的说明条显示所属相册名称。
6. 页面不再渲染底部键盘提示文案。
7. 360px 视口下页面无横向溢出，年份快捷导航可用，媒体查看器仍能打开。
8. Hash 路由、媒体 URL、主题切换与查看器行为不变。

## 实现说明

留影页是用户可见的浏览页布局与信息层级变化，因此按 full 记录本变更；两个主题各改自己的 `ThemePages.tsx` 与 `ThemePages.module.css`，不引入共享 UI 组件或新依赖。
