# 线缝相册主题与首页规格

## 背景与目标

当前海边、草原双主题和两段整屏首页与 Android 酒红相册开屏及图标不一致。用户在 Visual Brainstorming Companion 选择 A1 居中阅读页，并确认线缝书脊、无句号大字小字、横向照片与手机手滑。

目标是全站只保留一套相册主题。首页是一张可阅读、可自动翻动主回忆的相册页；现有静态内容、媒体、查看器与播放职责不变。

## 行为

- 首页桌面为居中的奶油纸页，酒红封边和左侧线缝装订。左上显示大标题「把日子，一页页翻开」和小字「那些珍贵的时光，慢慢再看一遍」，均不带句号。右上提供「浏览全部影像」，下方显示单张横向 3:2 照片，照片后露出同尺寸的剩余纸页；桌面在照片下提供上一页、播放或暂停、下一页。
- 手机为竖屏书页与横向 3:2 照片；不显示上一页、下一页及播放按钮。照片左右手滑翻页。点击照片暂停或继续自动翻页，作为无额外常驻按钮的暂停入口；每页静止停留 2 秒，翻页约 900ms，落定后重新计时。
- 相册共有主回忆照片数加一张内页，最后一页为文字收束页。每向前翻一页，右侧待翻内页实际减少一张；向后翻则把左侧已翻内页翻回。照片跟随其所属纸页轻微倾斜。前翻由右向左卷起，曲线纸背与柔和投影跟随折线移动；回翻沿同一轨迹逆向展开，底页保留到落定。整个动效限制在内页范围，不伸出相册或遮盖标题，速度连续加速再减速。减少动态效果时立即切换。首页展示框固定 3:2，仅在此处对非 3:2 源图做居中裁切；相册详情和查看器仍保留原始完整画幅。
- 收束页文案为「翻到这里，先把书轻轻合上。这些日子没有走远，想念的时候，随时回来看看」，到达后停止自动播放，不从头循环；仍可手动返回前页。首页大标题在手机端分为「把日子，」与「一页页翻开」两行。
- 悬停或键盘焦点进入播放器时暂停自动翻页，用户显式继续可覆盖当时悬停；页面隐藏、查看器打开或卸载时停止计时，回前台不自动恢复。空照片不创建计时器，单张照片可自动翻至收束页，空态有明确指引。
- 「浏览全部影像」进入现有 `#/browse`。背景音乐的 playback 状态、命令和主题音频组件能力保留，但全站不挂载音乐组件，不显示按钮或 audio 元素，也不触发播放。相册、浏览、视频查看器沿用现有功能语义，但使用唯一相册主题的色彩、字体与装饰。
- 留影头图的相册插画融入同色的米黄页面背景，原图的方形浅底不得形成可见色块或接缝。
- 不保留主题选择入口、主题偏好读取或写入、旧主题应用。共用 `media-viewer` 不复制也不覆盖。

## 非目标与边界

不新增后端、数据库、登录或原生桥接；不修改媒体内容源和相册排序；不发布或推送。首页照片来自 `home-memory.json` 的构建期配置。Android 开屏与图标不在本次修改范围。iOS 现有蓝绿图标保持原状，后续如需统一另行变更。

## 验收

1. AC1：运行时只装配一种相册主题，所有路由无主题切换入口、行为与偏好存储。
2. AC2：桌面首页可见居中纸页、线缝、左上无句号大字和小字、3:2 完整照片、等大层叠页、浏览全部入口与桌面播放控制；照片与内页一起轻微倾斜。
3. AC3：手机首页 3:2 照片完整可见，手滑前后页；无常驻播放和前后页按钮，点击照片可暂停或继续自动翻页。
4. AC4：内页总数等于照片数加一，前翻右侧待翻页逐次减少，回翻恢复；前后翻页沿同一卷页轨迹反向运行，曲线纸背与阴影连续变化，不越出内页范围；最后一页为文字并停止自动播放；减少动态效果立即换页；计时器按可见性、悬停、焦点与卸载条件清理。
5. AC5：留影、相册、查看器仍可使用；背景音乐能力保留但没有入口、audio 元素或播放；playback 为媒体播放状态唯一来源，`media-viewer` 全站唯一。
6. AC6：检查、构建、端到端及桌面/手机视口、子路径验证通过；文档与实现一致，未验证项明确记录。

## 实现选择

复用现有 `albums` 首页手势及计时控制，使用原生 SVG 曲线、裁切和渐变实现卷页，`requestAnimationFrame` 推进动画，`prefers-reduced-motion` 直接切换。候选外部翻页库偏向完整双页书本布局，会增加包体积和 DOM 约束；本次只有单页卷曲，选择主题内局部组件并明确取消动画帧的归属，不新增依赖。继续复用现有 `lucide-react` 图标与 `react-photo-album` 浏览能力。
