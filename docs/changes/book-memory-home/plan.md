# 实施计划

1. 保留 `app` 对路由、查看器会话、音乐状态的所有权，删除主题状态和切换命令。`themes` 仅导出相册主题应用与无 UI 契约。
2. 将现有海边主题目录转换为 `book`，保留经过验证的浏览、相册、音乐实现及共用查看器挂载，删除草原与主题按钮。更新 token 和内容页视觉，使全站协调。
   移除只供旧海边玻璃首屏与主题按钮使用的 `react-liquid-glass-svg` 依赖及锁文件条目。
3. 用 `book/ThemeHome.tsx` 和专属 CSS 实现已确认的单页相册：首页主回忆继续调用 `albums` 状态与手势契约；建立翻页动画的创建、完成、取消与卸载清理。
4. 调整相关测试以覆盖唯一主题、手机手滑、桌面控制、翻页与静态子路径。运行 `npm run check`、`npm run build`、`npm run test:e2e`，桌面和手机浏览器核对视觉与流程。
5. 更新需求、架构、模块契约、README 与决策文档；记录真实验证及代码审查结论。回退可恢复 `origin/main` 上的双主题文件与基线，不改变内容源。

## 用户体验修订（2026-09-30）

1. `albums` 将非循环书页进度扩展到照片数加一的收束页；到达末页立即停止自动播放，保留手动回翻。
2. `book/ThemeHome` 根据当前页渲染实际剩余内页；已翻页在回翻动效中从书脊左侧返回，以同一左侧书脊完成正反向翻页。翻页期间锁住重复动作，完成或卸载时清理动画计时器；减少动态效果即时切换。
3. 手机标题明确两行；移除 `BookMusicToggle` 的运行时挂载，保留 playback 音乐逻辑及组件文件供未来使用。
4. 更新相应测试与基线，复跑检查、构建、桌面和手机端到端及静态子路径；核对可见页数、收束、音频不播放与视觉。

## 翻页动效重做

使用原生 SVG 裁切、曲线纸背与渐变阴影实现连续卷页，替换整张照片的刚性 3D 旋转。动效限制在内页范围，回翻使用相同几何的逆向进度。主题内新增局部 PageTurn 组件，动画帧由组件创建和取消，完成回调由首页提交回翻索引和释放锁；减少动态效果直接切换。复用平台能力，不新增依赖。验证动画中途不会溢出内页、回翻底页不提前改变、末页停止和路由卸载清理。
