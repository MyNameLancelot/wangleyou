# 首页第二屏改造计划

1. 海边与草原各自改造 HomePage 第二屏结构：移除标题区、计数与按钮控制区，加入玻璃底板、左右箭头与保留的进度条。（验收 1、2、4）
2. 两主题分别编写第二屏样式：3:2 画框、居中玻璃底板、箭头定位（桌面在玻璃两侧、窄屏叠在照片边缘）、淡入动效与减少动态降级。（验收 2、3、5）
3. 自动播放暂停条件加入指针停留与焦点状态；箭头点击重置计时；保留查看器与进度条语义。（验收 3、4）
4. 更新浏览器用例：首屏用例改从相册页进入，第二屏用例改为验证箭头切换、悬浮暂停、无标题无计数与进度条存在。（验收 1、3、4）
5. 同步需求与总架构基线，运行 check、build、E2E 与截图核对后归档。（验收 1–5）

第二轮追加：

6. `albums/home-memory.ts` 新增播放意图写入、横向滑动意图与点击容差纯契约，并补单元测试；两套主题 UI 只消费公开入口。（验收 7、8）
7. 两主题第二屏：照片按钮去掉查看器入口，改为按 `playing` 暂停/继续；新增照片下方的播放按钮与固定预留行；接入第二屏内触摸横向换图并忽略滑动后的补发点击。（验收 6、7、8）
8. 两主题样式：900px 及以下隐藏箭头并释放箭头留白，新增播放按钮视觉与焦点样式。（验收 3、7）
9. 更新浏览器用例并同步需求、总架构、themes/albums 模块说明与变更记录，运行 check、build、E2E 与移动端截图核对。（验收 1–8）

第三轮追加：

10. 把 `HOME_MEMORY_INTERVAL_MS` 从 5000 下调（先 3500，第四轮定为 2000），同步单元测试与浏览器用例的时间断言，并更新需求基线与变更记录。（验收 9）

第四轮追加：

11. 第二屏加入鼠标按住拖动换图：按下超过 8px 容差才接管指针并捕获，位移达到 56px 且横向占优才换图，拖动结束按滑动处理而不触发点击；同步 themes 模块说明、规格与浏览器用例。（验收 10）

第五轮追加：

12. 第二屏加入触控板横向滚动换图：`deltaX` 占优时按 56px 阈值累积换图，纵向滚动保持切屏，横向滚动不产生页面横向滚动；补充纯契约、单元测试与浏览器用例。（验收 11）

第六轮追加：

13. 把触控板换图改为手势级去重：`reduceHomeMemoryWheel` 记录手势起点与是否已换图，动量事件不再重复换图；补单元测试与「一次手势只换一张」的浏览器用例。（验收 12）
14. 背景音乐加入音量：playback 增加 `volume` 与 `setBackgroundMusicVolume`，命令契约增加 `setVolume`，两套主题的音乐入口各自渲染与圆形右对齐的音量面板，audio 元素投影该音量；同步需求、总架构、playback/themes 模块说明与用例。（验收 13）

第八轮追加：

15. 触屏端加入长按展开音量：500ms 长按展开、释放时忽略补发点击、面板外点击与 Esc 收起，移动超过 8px 取消长按；用 CDP 触摸事件补移动端用例。（验收 16）
16. 音量面板改为磨砂玻璃表面（半透明渐变色染 + 22px 模糊 + 饱和增强，保留无模糊降级），并更新需求、模块说明与验证记录。（验收 17）

第九轮追加：

17. 音量面板改为「仅在音乐播放状态可展开」：悬浮/聚焦/长按都要求 `data-playing="true"`，暂停时 `aria-hidden` 且滑块 `tabindex=-1`；长按在暂停时按普通点击处理。（验收 18）
18. 面板改用主题色相的有色玻璃并加深投影，使第二屏浅色背景上也能看出玻璃质感；滑块改为自绘的深色圆角轨道 + 主题色椭圆滑块。（验收 19、20）

第十轮追加：

19. 修复两屏音乐控件毛玻璃失效：移除音乐控件包装层上会隔离 `backdrop-filter` 取景的 `filter` 投影，按钮圆形与面板阴影改用 `box-shadow`，并下调圆形表面与音量面板底色透明度，使首屏照片与第二屏背景都能透视模糊纹理；同步需求与 themes 模块说明。（验收 21）
20. 音量面板移除喇叭图标仅保留居中滑块；滑块改为约 2px 细线轨道 + 主题色细长方形滑块，保留 104×44 命中区、键盘与拖动调节；更新浏览器用例与截图核对。（验收 22、23）

第十一轮追加：

21. 面板色染改为音乐图标同色相的深色玻璃（海边深青、草原深绿），轨道改为浅色细线，使第二屏浅色平底上也能明显看出磨砂透视；滑块改为直角长方形（圆角 0），保持 6×20 尺寸与 104×44 命中区；截图核对两主题两屏并同步需求与模块说明。（验收 24、25）

第十二轮追加：

22. 滑块改纯白直角长方形（约 4×18px），轨道细线透明度下调与纯白滑块区分；两主题面板底色透明度再下调（约 0.28–0.44）让第二屏浅底透出玻璃透视；截图复核两主题两屏。（验收 26、27）
23. playback 新增注入式 `readBackgroundMusicPreference`/`writeBackgroundMusicPreference` 纯契约与单测；App 初始化读取缓存并只在显式 toggle/音量调整时写回；两主题音乐组件在 blocked 状态监听一次性首手势（控件内部手势除外）恢复播放；新增「刷新恢复」浏览器用例并同步需求、架构与模块文档。（验收 28）

第十三轮审查修复：

24. playback 增加前台待恢复状态与纯函数：页面隐藏时保留播放意图但停止实际播放，回到前台不自动 `play()`；音乐按钮点击清除待恢复并恢复播放。同步单测与两主题接线。（验收 29、30）
25. 主回忆 HomePage 增加前台待恢复状态；页面隐藏时停止计时，回前台不自动计时，显式恢复后才继续。显式恢复设置临时交互覆盖，鼠标移出或焦点离开播放器后清空。补充纯契约与浏览器用例。（验收 30、31）
26. 两主题主题切换开关移除外层 `filter: drop-shadow`，阴影改由 LiquidGlass `box-shadow` 表达；补充无外层 filter 断言与浏览器视觉回归。（验收 32）
27. 保持背景音乐为主题私有资产，并把 MP3 重编码为 96 kbps mono 媒体资产；在素材说明中如实登记当前来源未确认、非商业占位的限制。同步 requirements、architecture、README 与模块文档。（决策 4B、5、6A）
28. 把 `Route` 抽到无 UI 共享路由契约，themes 与 app 都消费公开类型，消除 themes → app → themes 的模块级循环；更新 SDD 依赖检查与 module 文档。（验收 8A）
29. 修正文档与变更记录：默认音乐意图保持 playing、程序性暂停不写存储、白色滑块、`reduceHomeMemoryWheel` 命名、过期验收项和 README 视频能力；最终运行 check、build、E2E 并记录证据。

第十四轮追加：

30. 两主题首页移除首屏 `border-bottom` 与第二屏 `border-top`，让两屏背景直接相接，消除切屏时出现的亮线；用对照注入验证断言能复现旧亮线。（验收 33）
31. 两主题第二屏把左右箭头、播放按钮与进度条轨道改为毛玻璃配方（半透明色染 + 背景模糊 + `box-shadow`，无白色描边），并补 `@supports not (backdrop-filter)` 的不透明降级。（验收 34、35）
32. 主题私有资产迁移到 `public/media/themes/<主题>/`，同步两主题组件引用、素材说明、README、活动规格与浏览器用例；顺带修正用例中仍断言旧首屏资源名导致的既有失败。（验收 36）
33. 同步需求与 themes 模块说明，运行 check、build、E2E，并用两主题桌面/移动截图与逐行亮度扫描记录交界与毛玻璃证据。
34. 修复 CI 暴露的两处既有用例不稳定：回顶断言改为在同一语义下重发并要求页面能停在顶部；显式恢复用例改用真实节奏验证并去除「点击照片后指针离开即恢复播放」的错误假设（点击会把焦点留在播放器内，按已确认规格此时保持暂停）。

第十五轮追加：

36. 删除未被引用的 `public/media/themes/beach/home-hero-2k.webp` 并同步素材说明。（验收 39）
37. 两主题在首页两屏之间加入跨屏淡入装饰层：海边用第二屏背景图、草原用第二屏渐变，在交界带内渐显；层位排在第二屏之下，避免覆盖底板与控制。（验收 37、38）
38. 更新常驻用例断言装饰层的可访问性与堆叠关系，并用交界窄带逐行亮度扫描 + 隐藏装饰层对照截图记录证据；同步需求、总架构与 themes 模块说明后运行 check、build、E2E。

回退方式：恢复第二屏标题区、计数、按钮控制区与 16:10/4:3 画框，恢复照片按钮的查看器入口与移动端箭头，并还原对应测试与文档。
