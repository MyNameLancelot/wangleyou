# 首页第二屏改造规格

状态：实施中（第十二轮已实现，第十三轮审查修复实施中）

## 目标

把首页第二屏（主回忆）从「标题 + 照片 + 按钮控制区 + 计数」改为「居中照片 + 毛玻璃底板 + 左右切换箭头 + 进度条」，画框固定为标准相机画幅。
第二轮追加：首页不再进入大图预览，点击照片改为暂停/继续自动播放并在暂停时显示播放图标；移动端不显示箭头，改用第二屏内横向滑动换图。

## 用户确认的口述要求

第一轮：

- 删除 `HOME MEMORY` 与「主回忆」标题区。
- 删除右上角「第 N / M 张」计数。
- 删除整块按钮控制区：上一张、暂停、下一张、查看当前照片、查看相册链接。
- 照片居中，后面垫一块比照片略大的毛玻璃底板。
- 左右各一个切换图标（箭头）用于上一张/下一张。
- 照片固定长宽，采用一般相机画幅 3:2，缓慢自动播放。
- 进度条能力保留。

第二轮追加：

- 首页目前不要预览：点击第二屏照片不再进入查看器。
- PC 和移动端点击照片都暂停自动播放，暂停后照片下方显示一个播放图标。
- 移动端第二屏不显示左右箭头，改为横向滑动切换照片。
- 横向滑动只在第二屏内生效，纵向滑动仍然切换首页两屏，音乐按钮上的触摸不计入滑动。

第三轮追加：

- 自动播放节奏偏慢，需要更合理。

第四轮追加：

- 桌面浏览器希望像触摸屏一样，按住鼠标左右拖动即可换图。
- 自动播放改为 2 秒一张。

第五轮追加：

- 确认 PC 端换图覆盖鼠标按住拖动与触控板横向滑动两种习惯用法。

第六轮追加：

- 触控板双指滑动只应换一张，实测一次手势换了好几张。
- 鼠标悬停音乐图标时，在图标下方显示音量控制组件，并与音乐图标右对齐。

第七轮追加（第六轮引入的问题修复）：

- 触摸板滑不动了。
- 点击照片切换播放/暂停的能力没了。
- 音量组件占位太大、不需要显示百分比，希望更纤细。

第八轮追加：

- 移动端没有 hover，音量的呼出方式确认为长按音乐按钮展开。
- 音量控制组件要磨砂玻璃效果。

第九轮追加：

- 第二屏的音量面板看不出磨砂效果变化。
- 音量组件应只在音乐处于播放状态时、悬浮音乐图标才展示。
- 滑块要改成参考图样式：深色圆角轨道 + 椭圆形滑块。

第十轮追加：

- 首页音乐播放组件在首屏、第二屏仍都看不出毛玻璃效果，需要修复为真实可透视的磨砂玻璃。
- 音量面板里的小喇叭图标不要了。
- 音量滑块应是瘦瘦的长方形，不要椭圆。
- 音量刻度（轨道）应是一条比较细的线。

第十一轮追加：

- 音量滑块要直角长方形（不要圆角）。
- 整体音量控制组件的颜色和音乐图标用同一个（深色图标色相的玻璃面板）。
- 第二屏的音乐相关组件仍要能看到毛玻璃效果（浅色平底上用深色玻璃才能显出透视）。

第十二轮追加：

- 滑块用白色效果更好，再细一些。
- 第二屏音乐组件现在看起来是灰色，要确认并真正呈现毛玻璃效果。
- 刷新后音乐直接被禁止，应该本地缓存播放状态，刷新后能恢复（浏览器拦截时至少首次交互即恢复）。

第十三轮追加：

- 保持首次访问默认尝试播放背景音乐（用户确认修改“必须主动开启才默认播放”的候选方案）。
- 页面回到前台后，主回忆和背景音乐都等待用户主动恢复，不自动恢复。
- 用户显式恢复主回忆后，即使指针仍在播放器内或焦点仍在播放器内也立即计时；指针或焦点真正离开后恢复普通暂停规则。
- 背景音乐继续作为主题私有资产引用，不新增相册内容配置。

第十四轮追加：

- 上下屏切换时两屏交界处会出现一条线，要求去掉。
- 第二屏的左右箭头与进度条也要毛玻璃效果。
- 主题私有的背景图与背景音乐按主题分目录存放，不再平铺在同一目录下靠文件名前缀区分。

第十五轮追加：

- 删除未被任何主题引用的旧首屏图。
- 两屏交界要完全看不出接缝，不只是去掉那条线。

## 非目标

- 不改变两屏吸附、滚轮/键盘/触控落点切换与切屏锁。
- 不改变查看器、路由、playback 或内容配置；相册页与全部影像页的缩略图仍然点击进入查看器。
- 不改变主回忆队列派生规则（最多 12 张最新照片、排除视频）。
- 不接管键盘左右方向键换图；桌面换图只提供左右箭头、按住鼠标拖动与触控板横向滑动三种方式。
- 不把背景音乐路径加入内容配置；当前音乐属于主题私有资产。
- 不改变第二屏画框尺寸、按钮命中区、自动播放节奏与换图手势；不删除任何现有资产。

## 行为

- 第二屏保留照片、进度条与暂停后才出现的播放按钮；桌面端另有左右箭头，宽度 900px 及以下不显示箭头。
- 照片画框 3:2，照片以 `object-fit: contain` 完整显示，不裁切；画框外由玻璃底板承托。
- 自动播放每 2 秒前进一张，切换带约 600ms 淡入；指针停留或键盘焦点进入第二屏时暂停，移开后恢复。
- 点击照片暂停自动播放并在照片下方显示播放按钮；再次点击照片或点击播放按钮即恢复播放并隐藏按钮。
- 播放按钮位于照片与进度条之间、水平居中，命中区不小于 44×44px；该行高度固定预留，暂停前后照片与进度条不因此位移。
- 宽 900px 及以下在第二屏内横向滑动切换上一张/下一张：横向位移达到 56px 且大于纵向位移才判定为换图；纵向滑动继续切换首页两屏；第二屏之外的触摸（如右上角音乐按钮）不参与换图。
- 桌面端按住鼠标在第二屏内左右拖动同样换图：位移达到 56px 且横向占优时才接管指针并换图，一次拖动只换一张；未达阈值时完全不接管指针，因此普通点击（含触摸板点按时的轻微位移）仍按点击处理，拖动结束时浏览器补发的点击由指针捕获拦截。
- 桌面端触控板横向滚动（`deltaX` 占优）在第二屏内按同一 56px 阈值累积后换图，手指向左前进一张；纵向滚动仍然切换两屏，横向换图不产生页面横向滚动。
- 触控板换图按手势去重：同一手势内累积到位只换一张，事件间隔小于 `HOME_MEMORY_WHEEL_GAP_MS`（400ms）时继续算同一手势，因此慢速滑动也能累积到阈值换一张；停手超过该间隔后才开启下一次手势。
- 每个音乐入口在图标下方提供一个音量滑块面板：默认收起（`opacity: 0` 且不接收指针），鼠标悬浮音乐按钮或键盘聚焦（`focus-within`）时展开，与音乐圆形右边缘对齐；面板只保留滑块（第十轮起移除喇叭图标），不显示百分比文字，高度约 26px、宽约 122px；滑块 0–100%、步长 5%，命中区仍不小于 44×44px，写入 playback 的唯一音量状态。
- 触屏端长按音乐按钮 500ms 展开音量面板：长按不触发播放/暂停切换（释放时浏览器补发的点击被忽略），点击面板外或按 Esc 收起；移动距离超过 8px 取消长按，避免与滚动、点击冲突。
- 音量面板使用磨砂玻璃表面：半透明渐变色染 + 26px 背景模糊与饱和增强，无白色描边或高光边；不支持背景模糊时回退为更不透明的同色底。音乐控件包装层不得使用会隔离 `backdrop-filter` 取景的 `filter` 投影：按钮圆形与音量面板的阴影一律用 `box-shadow` 表达，第十轮起圆形表面与面板同步下调底色透明度，使首屏照片与第二屏背景都能透视出模糊纹理。
- 第十一轮起面板色染改用音乐图标同色相的深色玻璃（海边偏深青 `rgb(10 74 95/…)`、草原偏深绿 `rgb(45 72 44/…)`），使浅色平底的第二屏也能明显看出透视与模糊；轨道为浅色细线，与深色面板形成对比。第十二轮起面板进一步降低底色透明度（约 0.28–0.44），避免在第二屏浅底上读成灰色实底。
- 音量面板只在音乐播放状态可展开：`data-playing="true"` 时悬浮、键盘聚焦与长按才生效；暂停时面板对整个无障碍树隐藏，滑块移出键盘顺序（`tabindex="-1"`），长按按普通点击处理。
- 面板色染改为主题色相的有色玻璃（海边偏青、草原偏嫩绿）并加深投影，使浅色背景的第二屏上同样能看出玻璃质感，而不是一块白色胶囊。
- 滑块为自绘样式：约 2px 高的浅色细线轨道 + 高约 18px、宽约 4px 的纯白直角长方形滑块（第十二轮起），不使用原生 `accent-color` 渲染；命中区仍是 104×44px。
- 背景音乐的播放意图与音量写入 `localStorage`（键 `wangleyou:background-music`，playback 提供注入式读写纯契约并做校验归一化）：只有用户显式的播放/暂停切换与音量调整才写存储；浏览器拦截、页面隐藏等程序性状态变化不写。刷新后按缓存初始化意图与音量：缓存为播放时先尝试自动播放，被浏览器拒绝则进入 blocked 视觉，任意首次指针或键盘交互（音乐控件内部手势除外，按钮自身点击走原 toggle 路径）即用同一手势恢复播放；缓存为暂停时刷新保持暂停、不尝试播放。存储不可用时静默回退默认行为。
- 页面隐藏时，若主回忆当前显式处于播放态，记录“回前台待恢复”；回到前台不重启计时器。用户点击照片、播放按钮或其他显式恢复操作后才开始继续自动播放。背景音乐同理：隐藏时停止播放并记录“回前台待恢复”；回到前台不自动调用 `play()`，用户点击音乐按钮恢复。
- 主回忆的指针停留和区域内焦点是临时暂停条件；用户显式恢复播放时，若当时指针或焦点仍在播放器内，则覆盖该临时暂停，直到指针移出或焦点真正离开播放器。再次进入时恢复普通暂停规则。
- 滑动换图后忽略浏览器随后补发的点击，避免一次滑动同时暂停自动播放。
- 打开查看器、切回首屏、标签页隐藏或组件卸载时同样停止计时。
- 首页路由不再打开查看器，`viewerOpen` 仅作防御性保留，非首页查看器入口不变。
- 第二屏不再有可见标题，因此保留 `aria-label="主回忆"` 作为区域名称；进度条以 `aria-label="主回忆进度"` 提供名称。
- 照片按钮名称随播放状态变化（播放中「暂停主回忆自动播放：…」，暂停后「继续主回忆自动播放：…」），播放按钮名称为「继续播放主回忆」。
- 首页两屏背景直接相接，不再渲染 `border-top`/`border-bottom` 之类的 1px 分隔线；两屏各自的背景图与渐变继续按既有规则渲染。第十三轮之前交界处同时存在首屏 `border-bottom` 与第二屏半透明 `border-top`，实测形成约 2px 的亮线。
- 第二屏的左右箭头（桌面）、暂停后的播放按钮（桌面与移动端）与进度条轨道使用与音乐控件一致的毛玻璃配方：半透明色染 + 背景模糊 + `box-shadow` 投影，不使用白色描边；背影是纹理沙地或浅色平底时都能透视出模糊后的背景；不支持背景模糊时由 `@supports not (backdrop-filter: blur(1px))` 回退为更不透明的底色。进度条的填充部分继续使用主题色实色，保证进度可读。
- 主题私有资源按主题目录组织：`public/media/themes/<主题>/home-hero.webp`（首屏与浏览页头图）、`public/media/themes/<主题>/home-memory.webp`（仅海边第二屏背景）、`public/media/themes/<主题>/music.mp3`（背景音乐）；`public/media/theme/` 与 `public/media/audio/` 两个顶层目录不再存在。相册内容资产仍在 `public/media/` 顶层、`public/media/thumbs/` 与 `public/media/video/`，内容配置只引用这些内容资产。
- 首页两屏交界由主题私有装饰层（`data-home-seam`）用第二屏背景做跨屏淡入：海边使用同一张第二屏背景图，草原使用同一段第二屏渐变；层从 `100dvh - 淡入带` 起覆盖到第二屏底部，遮罩在淡入带内由全透明渐变到不透明。层位于首屏之上、第二屏之下（第二屏 `z-index: 3`、层 `z-index: 2`），因此只影响交界带，不覆盖第二屏的毛玻璃底板、照片、箭头与进度条。淡入带为 `clamp(56px, 9dvh, 150px)`。
- 不支持 `mask-image`（含 `-webkit-` 前缀）时装饰层保持 `display: none`，退回两屏直接相接的既有行为。

## 开发默认决策

- 用户确认「点击照片暂停、下方播放图标继续」；再次点击照片同样恢复播放，避免暂停后照片成为无响应控件。
- 移动端的判定沿用既有窄屏断点 900px，与箭头原本改叠在照片边缘的断点一致；该断点以下不渲染可见箭头。
- 播放按钮所在行始终预留 44px 高度，换取暂停切换时照片不跳动。
- 第三轮起把自动播放间隔从 5 秒下调，当前为 2 秒（第四轮确认，淡入仍约 600ms），由 `HOME_MEMORY_INTERVAL_MS` 单点控制，便于后续继续微调；不下沉为用户可配置项。
- 拖动阈值沿用滑动的 56px：只有真正跨过阈值才接管指针，“点击 + 轻微位移”不再被吞掉；不再使用滑动后的点击守卫计时器，避免吞掉拖动后紧跟的正常点击。
- 音量面板保持在无障碍树中（不使用 `display: none` 或 `visibility: hidden`），保证键盘 Tab 能进入并在聚焦时展开；每个首页入口各自渲染一个滑块，但共享同一音量状态，与两个音乐按钮的既有约定一致。
- 第九轮把「保持在无障碍树中」改为仅在播放状态可达：暂停时面板 `aria-hidden` 且滑块 `tabindex=-1`，避免出现看不见却能被 Tab 选中的控件；播放时恢复可聚焦与可访问名称。
- 移动端长按展开为本次确认的正式入口；桌面端仍以悬浮/聚焦为主，长按同样可用。面板不常驻显示，避免挡住照片。
- 第十四轮目录命名采用 `public/media/themes/<主题>/`：父目录用复数表示主题资源集合，主题名作为子目录，文件名去掉主题前缀，由目录表达归属；应用只需改动字面路径，Vite 与静态服务无需额外配置。
- 第十四轮曾把未被任何主题引用的旧首屏图保留为 `public/media/themes/beach/home-hero-2k.webp` 待确认；第十五轮按用户指示删除该文件，素材说明同步移除对应行，已引用的主题资产不受影响。
- 毛玻璃数值：箭头与播放按钮 `blur(18px) saturate(150%)`，底色透明度海边 0.42、草原 0.44；进度条轨道 `blur(14px) saturate(150%)`，底色透明度海边 0.38、草原 0.40；面板与按钮依旧不使用白色描边或高光边。

## 验收条件

1. 第二屏不渲染标题、张数计数、常驻控制区与相册链接；桌面端播放中可交互元素正好是两个箭头、照片与一个进度条。
2. 照片画框桌面与移动端均为 3:2，照片完整可见不裁切，玻璃底板不带白色描边。
3. 桌面左右箭头为至少 44×44px 目标，可切换上一张/下一张；900px 及以下不显示箭头。
4. 指针停留或键盘焦点进入第二屏时自动播放暂停，移开后恢复；进度条保留并反映当前进度。
5. 两屏吸附、滚轮/键盘切换、主题切换、减少动态与既有查看器流程回归通过。
6. 首页第二屏点击照片不打开查看器；相册页与全部影像页点击缩略图仍打开查看器。
