# Android 启动画面规格

## 问题与目标

原 Android 加载界面是深绿背景加默认转圈，与「乐悠时光」已选图标不协调。用户确认「翻开相册 + 奶油白纸张」方向后，又反馈封面转动缺乏立体感、像翻纸，并要求封面完全翻开、书脊不折、右上角提供可跳过的入口。

## 范围

- 加载层在奶油白纸张上展示一本相册：后封面、纸页块与照片、带金线的书脊、封面正面与内侧衬页。
- 封面从 0° 转到接近摊平的 −168°，转轴落在书脊外缘，书脊保持直立不折；转过 90° 时正面换成奶油色内侧衬页，避免出现镜像封面。
- 立体感由封面明暗变化（翻开时加深）、书脊内侧沟槽阴影、随开合拉伸与变深的落影共同表现；透视相机距离取远值，避免近距透视把封面放大成一张大纸。
- 相册随翻开过程水平位移，结束时摊开的书仍在画面中央。
- 冷启动至少展示到完全翻开并停稳（约 2.9 秒），再约 0.3 秒淡出；网页就绪后右上角出现毛玻璃「跳过」按钮，点击立即结束动画。
- Android 系统冷启动背景使用同一奶油白，避免进入原生加载层前闪深色底。
- 主框架失败时停在半开的相册并显示同风格错误说明与「重新连接」按钮；重试重新进入加载状态。
- 尊重系统减少动画设置；不依赖外部图片、字体或网络提供启动视觉。

## 非目标

- 不改变线上网页首页、iOS 容器、桌面图标或网站资源加载机制。
- 不引入第三方动画库，也不为动画强制等待完整循环后才显示已就绪的网页。

## 验收

- A1：冷启动与主框架重载期间没有深绿空屏或系统默认转圈；奶油白贯穿状态栏与主体，相册、名称与加载提示完整显示。
- A2：封面完整翻开到接近平摊，书脊保持直立；过 90° 后显示内侧衬页而非镜像封面，摊开后左右两页宽度与高度协调（模拟器实测左页 118px、右页 100px、高度约 143px）。
- A3：翻开过程中落影与封面明暗随角度变化；相机距离不产生把封面放大的鱼眼效果。
- A4：网页就绪后动画不被截断，至少到完全翻开停稳再淡出；期间显示右上角毛玻璃「跳过」，点击后 0.3 秒内进入网页。
- A5：主框架断网或 HTTP 错误显示静态半开相册与重试入口，子资源失败不覆盖网页；重试后恢复加载状态。
- A6：开启系统减少动画时画面完整可读且不循环运动。
- A7：动画、落影、跳过按钮与延时任务都由 Activity 管理，全屏视频、返回键、安全区域与销毁清理维持原行为。
