# Android 启动画面实施计划

1. 在 Android 容器内建立独立原生启动覆盖层，用平台 View 与 GradientDrawable 拼出后封面、纸页、书脊、封面正面与内侧衬页；系统冷启动背景设为同色。
2. 用关键帧属性动画驱动封面旋转、正面/衬页换面、封面明暗、相册位移与落影；渲染用平台 View 动画，不新增依赖。
3. 管理加载、就绪等待、跳过、主框架失败与重试状态：冷启动至少播到完全翻开停稳，网页就绪后显示毛玻璃「跳过」，失败时停在半开相册。
4. 同步需求与 Android 模块契约；构建 Debug/Release，在 API 34 模拟器逐帧核对翻开、换面、书脊、跳过与断网恢复，运行 SDD 检查与差异审查。
5. 回退可恢复此前的 ProgressBar/错误面板实现，无数据迁移。

平台能力选择：现有工程只有 Android SDK；ObjectAnimator 关键帧与 View 的 rotationY、cameraDistance 足以完成开合、换面与落影，不需要第三方 3D 引擎。相机距离取远值（约 1200dp），否则近距透视会把封面放大到约 1.4 倍。
