# Android 翻开相册图标

## 背景与确认

旧图标把含文字的大相册画面放在自适应图标背景层，家庭 Android 真机上圆形裁切不完整。用户要求不再突出「乐悠时光」文字、突出相册本身，并在 Visual Brainstorming Companion 选择 B「翻开相册」。

## 行为

- 桌面标签继续是「乐悠时光」；图标画面内无文字。
- 图标主体为打开的酒红色相册，奶油白纸页与照片角清晰可认；背景为奶油白纸张。
- 主体缩入 Android 自适应图标安全区域；圆形、圆角裁切均不截断相册、纸页或主要阴影。
- 系统冷启动图标与桌面图标使用同一资源。

## 非目标

不改变包名、网页主题、iOS 图标、原生启动动画或业务功能。

## 验收

- A1：Android 桌面图标在圆形裁切下相册和纸页完整；小尺寸仍辨认出相册。
- A2：图标内没有「乐悠时光」或其他文字；桌面标签仍为「乐悠时光」。
- A3：使用既有家庭签名和更高 versionCode 生成可覆盖旧版的 Release APK，签名验证通过。
