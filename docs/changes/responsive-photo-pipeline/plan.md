# 响应式相册媒体管线实施计划

## 影响模块

| 模块 | 变更 |
| --- | --- |
| `scripts` | 新增可测试的 WebP 派生器、内容哈希清单和 CLI；保留现有人工 JPEG 压缩工具。 |
| `content` | `Photo` 增加已生成资源的尺寸与 `srcSet` 契约，构建期索引消费派生结果。 |
| `themes/beach`、`themes/grassland` | 各自用 `MasonryPhotoAlbum` 渲染主题私有详情图库。 |
| workflows | 缓存媒体派生器的 `.cache/media-variants`。 |
| docs | 更新维护方法、架构、模块契约、需求与依赖决策。 |

## 实施顺序

1. 先建立 source/derived 目录约定、忽略规则和媒体派生器的纯逻辑测试；测试哈希命中、改图、删图、尺寸、EXIF 清除与边界路径。
2. 迁移现有照片与元数据到 source 目录，生成 WebP 和包含尺寸/srcSet 的索引；扩展内容校验与资源存在性校验。
3. 调整 npm 脚本，使开发、校验和生产构建都先保证派生产物存在；更新 CI 缓存。
4. 安装并锁定 `react-photo-album`；两个主题各自接入 Masonry、保留现有缩略图与查看器交互。
5. 更新单元/E2E，重点覆盖派生缓存、资源选择、两主题三视口与点击查看器。
6. 同步基线文档与变更声明，执行完整检查和静态产物核对。

## 回退

回退本次新增依赖、媒体生成命令、`media-source/` 迁移和主题图库改动即可恢复原始公开资源模式；playback、路由和主题选择不受影响。派生目录与缓存均可删除后从源图重建。
