# 响应式相册媒体管线与瀑布流规格

## 背景与目标

相册详情曾从 `public/media/photos/` 直接读取原始图片，并用 CSS 多栏排布。用户要求原图继续纳入仓库维护，但不得随静态站点发布；网页应使用构建期生成的多尺寸 WebP，未变化图片在本地与 GitHub Actions 中不得重复编码。相册详情使用 `react-photo-album` 的 `MasonryPhotoAlbum`，按实际图片比例响应式排布。原始素材与派生资源都不使用 `photos` 中间层，以便照片与视频共用同一相册目录结构。

## 非目标

- 不接入图片 CDN、后端、登录、运行时转码或在线内容管理。
- 不改变 Hash 路由、playback 会话、查看器导航或主题切换语义。
- 不为当前小规模相册实现无限滚动、虚拟列表或第三方灯箱。
- 不删除或改写原图。

## 内容与派生资源

1. 原图、相册 `meta.json` 与 `home-memory.json` 位于 `media-source/`（相册目录直接位于该层，不使用 `photos` 中间层），并提交到 Git。
2. 构建期仅把派生 WebP 写入被 Git 忽略的 `public/media/<相册目录>/`；原图不得进入 `dist`。
3. 每张有效图片先按 EXIF Orientation 纠正，随后移除 EXIF、GPS 与其他元数据；保持原始宽高比，不放大。
4. 对每张图片生成不超过源图实际宽度的 480、960、1600、2560 CSS 像素宽度 WebP。输出路径包含源文件 SHA-256 的短哈希；同一图片各变体必须具有相同宽高比。
5. 媒体清单保存源字节哈希、处理配置版本、已生成的相对输出路径和尺寸。输入哈希与配置均未改变时必须复用现有 WebP，不能重新编码。
6. 删除源图或改变文件名后，构建器只能删除旧清单明确登记且位于派生相册目录内的过期派生文件；不得删除原图、主题资源或非清单文件。

## 内容模型与运行时行为

1. 每张 `Photo` 必须有源图实际 `width`、`height`，以及用于网页的默认 `src` 和 `srcSet` 候选图。
2. `src` 指向最大可用 WebP；`srcSet` 由全部有效 WebP 变体组成。`mediaUrl()` 仍是所有发布媒体 URL 的唯一入口。
3. 首页主回忆使用相同派生资源数据；查看器加载最大可用 WebP，不请求仓库原图。
4. `MasonryPhotoAlbum` 接收图片的宽高和 `srcSet`；相册详情显式提供 `sizes`，使浏览器按实际卡片宽度选择合适候选图。
5. 两套主题各自实现相册详情图库 JSX 与 CSS，但共享 content 的无 UI 数据模型。点击任一缩略图必须继续调用既有 `onOpen(album, mediaId)`，不创建第二份 playback 状态。
6. 照片的可访问名称、懒加载、加载失败可读反馈、键盘焦点替代提示及查看器打开行为必须保留。当前或未来视频在图库中继续以海报/占位形式呈现，不得因为照片库接入而丢失媒体顺序。
7. 相册详情沿用 `react-photo-album` 的默认响应式档位，不覆盖 `columns`、`spacing` 与 `sizes`：容器 ≥1200px 为 5 列/20px，600–1199px 为 4 列/15px，300–599px 为 3 列/10px，<300px 为 2 列/5px；`sizes` 由组件按实际列宽生成 `vw` 值。
8. 桌面相册详情 hero 的实际可见高度为 360–400px（内容区使用 `clamp(320px, 40dvh, 360px)`，标题区上边距使用 `clamp(48px, 8dvh, 72px)`）；平板和手机沿用既有更紧凑的 hero 高度，使 900px 高桌面首屏露出更多图库内容。
9. 留影页相册卡片中的照片封面同样使用现有 `srcSet`：根据两列手机、两列平板和三列桌面卡片宽度选择 480w 或 960w；不新增派生尺寸。视频海报和显式非照片封面保持原有单一资源回退。
10. 相册详情的内联图库以白色相纸相框呈现：组件 `padding={8}` 提供留白并计入列宽计算，主题样式只追加白底、8px 圆角与主题色轻投影；相框内不得再叠加描边、边框或图片内阴影，列数与间距档位不变。
11. 全站交互元素的聚焦框只在键盘导航时出现：全局样式对 `:focus:not(:focus-visible)` 的按钮、链接、表单控件、`summary`、`video` 与 `dialog` 统一清除描边，保留 `:focus-visible` 的主题色外圈；指针点击后不得残留浏览器默认（黑色）聚焦框。
12. 全站按钮在任何状态下都不得有边框：全局基线对 `button`、`[role="button"]` 与 `input[type=button|submit|reset]` 声明零边框；各主题删除按钮上的实色与透明占位边框，改用底色、圆角或投影表达层级（含查看器关闭、上一项/下一项、全屏、重试等控件与按钮样式的链接）。
13. 媒体目录不设 `photos` 中间层：原始素材为 `media-source/<相册目录>/`，派生发布资源为 `public/media/<相册目录>/`，两者层级一致且照片、视频共用；生成器缓存键包含派生输出布局版本，布局变化时必须重新生成而不是复用旧路径。
14. 「浏览全部影像」这类次要按钮（`.secondary`，按钮与链接共用）在悬浮、聚焦与按下时都不得改变底色或文字色，保持静态外观。

## 命令、缓存与 CI

1. 新增 `npm run generate:media`，负责派生资源和内容索引；`dev`、`validate:content` 与 `build` 在需要媒体时调用它。
2. 本地缓存目录为 `.cache/media-variants/`，不提交 Git；在缓存失效或缺少产物时可从原图完整重建。
3. GitHub Actions 除 npm 缓存外，恢复并保存 `.cache/media-variants/`。缓存键必须包括运行系统、所有源照片及配置/生成脚本哈希；使用前缀恢复最近缓存，使局部改图只重新编码受影响资源。
4. CI 仍从干净 checkout 完整构建，不依赖已提交的 WebP。缓存不可用时构建必须正确，只是耗时增加。

## 验收条件

- AC-01：构建后 `dist` 不含 `media-source/`，仅含派生 WebP；原图文件哈希与 mtime 不变。
- AC-02：同一输入第二次运行生成命令时所有图片显示缓存命中，未调用编码；只改一张源图时只重编该图的变体。
- AC-03：480/960/1600/2560 档位不放大，输出均为 WebP、无 EXIF，尺寸与原图比例一致。
- AC-04：删除一个源图后只清理其清单管理的 WebP，保留无关文件。
- AC-05：内容索引中的所有照片均有正整数宽高、可解析的 `src`、同宽高比的 `srcSet`；资源校验能定位缺失派生图。
- AC-06：海边、草原主题的相册详情在 390px、820px、1440px 无横向溢出；原始比例不裁切；点击、键盘焦点和查看器队列行为不回归。
- AC-07：GitHub Actions 恢复媒体缓存后仍执行内容校验、构建与浏览器测试；缓存缺失时亦能完整构建。
- AC-08：在 1440×900 视口，两个主题的相册详情 hero 高度介于 360px 与 400px 之间；≤1024px 的紧凑 hero 规则不变。
- AC-09：两个主题的 `#/browse` 相册照片封面均输出 480w、960w、1600w `srcSet` 与按断点声明的 `sizes`；普通卡片布局不请求超过其显示需求的候选图，且不增加新的 WebP 派生档位。
- AC-10：两个主题的相册详情在 1440px 视口为 5 列/20px 间距、820px 与 1024px 为 4 列、390px 为 3 列；图片 `sizes` 为组件自动生成的 `vw` 值；点击缩略图仍打开既有查看器。
- AC-11：两个主题的相册详情每张照片拥有 8px 留白、8px 圆角、白色底衬与可见投影，相框左右留白合计 16px（照片画面宽为列宽减 16px）；照片本身无描边与内阴影；键盘聚焦仍为提亮 + 上浮且无外描边；点击仍打开既有查看器。
- AC-12：在首页、留影页与相册详情用鼠标点击主题切换按钮后，该元素获得焦点但 `:focus-visible` 为 false 且 `outline-style` 为 `none`；随后按 Tab 时首屏可聚焦元素 `:focus-visible` 为 true 且外圈宽度大于 0，键盘用户仍能看出焦点位置。
- AC-13：首页、留影页与相册详情中的所有按钮在默认、`hover`、`focus`、`focus-visible` 与 `active` 五种状态下 `border-top-style` 均为 `none` 且宽度为 `0px`；查看器控件（关闭、上一项/下一项、全屏、重试）同样无边框仍可辨识与操作。
- AC-14：源素材与派生资源均不含 `photos` 中间层：`media-source/<相册目录>/` 存放原图与 `meta.json`，`public/media/<相册目录>/` 存放派生 WebP；内容索引中的 `src` 形如 `media/<相册目录>/<文件>.<哈希>.<宽度>.webp`；`dist` 不含 `media-source/`；重复生成命中缓存且路径不变。
- AC-15：留影页与空状态中的 `.secondary` 按钮/链接在默认、`hover`、`focus`、`active` 状态下计算样式一致（背景色与文字色不变）。
