# Android 透明状态栏规格

## 问题与目标

当前 Android 壳把状态栏背景固定为深蓝绿 `#072634`；在全面屏手机上形成与海边、草原主题不协调的色条。用户确认让网页背景延伸至顶部，系统时间、电量图标仍可见。

## 非目标

不隐藏状态栏，不改变网站主题内容、导航或媒体状态，不增加 JS 桥接及第三方运行时依赖，不更改 iOS。

## 验收条件

- A1：首页两种主题的背景延伸至状态栏后方，无固定深蓝绿色条；顶部使用渐隐暗色保护层，使白色系统状态图标可读且背景仍可见。
- A2：顶部按钮、浏览页标题和错误/加载界面避开状态栏与摄像头开孔；旋转、返回和视频系统全屏行为保持可用。
- A3：Android 15 及较早受支持版本均以透明状态栏展示；其他系统栏仍避免遮挡交互内容。
- A4：以相同家庭签名密钥构建版本号高于 1.0.0 的 Release APK，可覆盖已安装的家庭 Release 版；签名验证通过。
- A5：记录模拟器和真机分别获得的证据，不把模拟器结果当作真机结果。

## 用户确认

2026-09-28 用户选择“背景延伸到顶部，状态栏透明（推荐）”。Android 真机复验由用户执行。
