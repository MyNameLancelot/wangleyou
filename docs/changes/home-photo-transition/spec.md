# 首页相片左上角旋转抽走

日期：2026-10-10。分支：feat/home-photo-transition。状态：PC、手机和平板适配及浏览器验收完成，随本次 PR 交付，网站未发布。

## 确认设计与范围

用户指定以相片左上角为支点旋转抽走，已确认 PC 效果没问题，最新要求“手机端、pad端也适配、检查”。本轮恢复验证，统一各尺寸的纸片旋转，不再保留手机交叠分支。保留既有相册版式、桌面按钮、手机横滑与点击暂停；平板支持横滑并保留宽屏按钮。

## 行为与资源边界

整张相片连白边绕左上角顺时针旋出，下一张静止；回翻则目标纸片从同一方向转回。约900ms，PC 最大28度；手机和平板按可用左侧空间减小角度，避免照片转出屏幕或产生横向滚动。整张照片保持刚性，书本及标题不移动，允许离开原相片矩形。

保留2秒停留、末页停止、暂停、旧层 currentSrc 复用与输入 srcSet/sizes。目标慢加载时旧层静止，最长5秒后释放并显示既有加载/错误态。隐藏、减少动态效果时立即收尾；卸载释放动画、加载监听和定时器，不回调已卸载页面。先隐藏旧层再 cancel，避免终态撤销引发闪回。横竖屏切换期间立即收尾并释放锁，下一次按新尺寸开始。触摸取消须清除手势起点，纵向滚动不触发翻页。

只调整首页；不改查看器、内容或媒体托管，不新增依赖，提交、推送与 PR 已获用户收尾授权，不发布网站。

## 方案与依赖

沿用 React 与标准 Web Animations API。各端共用叠页层完整纸片快照；按纸片高度与到视口左边的空间限制旋出角度，最大28度，比例关键帧保持同一节奏。不创建断点分支或第二套状态。PhotoTransition 统一拥有动画、load/error、resize、偏好与可见性监听及等待定时器。无需新增动画库。

## 验收

- AC01：桌面1440×1000、手机360×800/390×844及横屏844×390、平板768×1024/820×1180及横屏1180×820，前进与后退整片左上角旋转，旧片退场无闪回；标题布局不跳动、无横向滚动。
- AC02：各端横滑/按钮、暂停/继续、重复操作锁、末页停止及返回正常；纵向手势和touchcancel不误翻；旋转屏幕时无残留层或锁。
- AC03：减少动态效果、隐藏/卸载、慢加载/错误/超时可恢复，复用候选图且不额外请求最大图。
- AC04：Node24 check、默认生产构建、根路径/子路径静态首页回归、SDD工作区检查通过；记录浏览器、视口和事实，视口模拟不等同真机。
