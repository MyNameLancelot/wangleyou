# Android 应用名称与图标实施计划

1. 记录已确认名称与文件命名规则，生成至少三个图标候选，供用户挑选。
2. 在用户确认图标后，以生成的浅木底相册 PNG 替换 `native/android` 图标资源并接入系统自适应图标；将 `AndroidManifest.xml` 应用标签改为「乐悠时光」，由 `native/android/package_family_apk.py` 从构建元数据读取版本号并生成交付副本，再更新本机扫码下载页的文件名。
3. 同步需求、Android 模块契约及 README；用现有家庭密钥重新构建 Release APK，验证签名、包名、版本、桌面名称、图标与下载文件名。
4. 使用模拟器核对更新安装与图标显示，交由用户在真机验证；记录证据并提交本地分支，不推送。

影响范围：Android 原生工程、本机安装包分发与对应文档。回退时恢复旧图标和标签，用更高 `versionCode` 输出同一签名的修订 APK。
