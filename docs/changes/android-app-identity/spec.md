# Android 应用名称与图标规格

## 目标

Android 安装后的桌面应用名称为「乐悠时光」。交付给家人的 APK 文件名采用 `乐悠时光-v<versionName>.apk`，本次目标版本为 `乐悠时光-v1.0.2.apk`。用户可从多个图标候选中选择最终图标。

## 范围与边界

- 修改 Android 应用标签和桌面图标；iOS 安装已暂缓，本次不更改 iOS 应用名称、图标或构建。
- Android Gradle 的内部输出路径可保持 `app-release.apk`；交付副本和扫码下载的建议文件名必须符合上述规则。版本变化时文件名随 `versionName` 同步。
- 图标应适合手机桌面的小尺寸展示，保持清晰，以相册和珍藏感表达家庭记忆。它是整个应用的通用标识，不以海边、草原、日落、山丘等单一主题景物为主体。用户选择深紫红色相册方案，封面中央使用清晰可辨的艺术字「乐悠时光」，四字必须准确，不加入其他文字。图标外部底色避免红色；暖白底和浅木书桌纹理为待比较方案。
- 不改变网站、原生容器导航、权限或媒体行为，不添加业务依赖。

## 验收条件

- A1：在 Android 安装后，桌面图标下显示「乐悠时光」。
- A2：家庭 APK 的交付文件名和扫码下载文件名为 `乐悠时光-v<versionName>.apk`；本次版本为 `乐悠时光-v1.0.2.apk`。
- A3：先提供至少三个可区分的图标候选；用户选定后才替换 Android 图标资源并重新打包。
- A4：最终图标在常见桌面裁切形状和小尺寸下可识别；签名、版本、安装更新行为保持正常。
