# 隔离主题首页设计

## 目标

将全站从共享 UI 的 Token 换肤模式调整为主题独立渲染：海边与草原主题各自拥有 React UI、样式、装饰和资产；两者严格遵守相同的页面交互契约。首页首屏玻璃采用轻量第三方组件 `react-liquid-glass-svg`，不再维护自制液态玻璃实现。

## 范围与非目标

- 范围：主题选择装配、导航、首页两屏、主回忆、相册页、媒体查看器、主题 CSS/资产、玻璃视觉、主题与 SDD 基线文档、自动化验证。
- 非目标：不改变相册内容模型、路由、查看器业务状态、播放模块、发布流程；不引入后端或设计稿工具。
- 草原主题不需要复刻海边视觉，但必须提供可用的独立首页和主回忆页面。

## 架构

`App` 只保留主题偏好读取、路由/查看器会话装配和主题应用选择。`themes/beach`、`themes/grassland` 分别导出完整站点 UI 应用，且主题目录间不得存在导入关系。主题应用不得导入共享 UI 组件；每个主题的导航、首页、Hero、主回忆、相册页、查看器、按钮、装饰、CSS 和媒体资产都在主题目录内维护。

共享代码只包含没有 JSX/UI 的交互契约与领域数据：两屏段落导航、滚动输入阈值和锁、触屏手势、键盘边界、主回忆队列、索引推进及 interval 生命周期。该契约位于非主题业务模块，主题只通过公开入口调用。共享逻辑不得输出 React 组件、CSS 类名、颜色或视觉配置。

主题间的可见页面结构允许不同；但必须满足相同操作语义：首页恰有 hero 与 memory 两个全屏逻辑段，滚动/键盘/触屏只能在相邻完整屏落点间切换，主回忆支持自动播放、暂停/继续、前后切换、打开查看器与相册入口；导航、相册浏览、查看器开关和媒体播放保持既有路由与状态含义。

## 视觉与依赖

海边主题首屏继续使用确认的 2560×1440 海滩图。其文字卡使用 `react-liquid-glass-svg` 的 `LiquidGlass`；卡片的文案、布局尺寸和主题色仅存在于海边主题中。草原主题自行使用草原背景、独立卡片与主回忆视觉，不能复用海边组件或 CSS。

新增用户可见的视觉效果时，先评估已维护的轻量第三方库。采用库前记录包体积、运行时依赖、许可、目标浏览器回退和无障碍影响；仅当没有合适库时才允许自制实现，并在变更记录说明原因。首屏玻璃的当前选型是 `react-liquid-glass-svg`：SVG 过滤器、无运行时依赖、约 2KB gzip，Safari/iOS 自动降级为可读玻璃。

## 错误与兼容性

主题名称非法或本地存储不可用时回退海边主题。`backdrop-filter`、SVG 位移或动态效果不可用时，文字卡仍须以足够不透明的底色和可见焦点保持可读、可操作。`prefers-reduced-motion` 取消非必要平滑和装饰动画，但不改变两屏落点和控制功能。

## 验收与验证

1. 任一主题 UI 不会导入另一个主题的文件，且不会导入共享 React UI 组件；静态检查覆盖该约束。
2. 海边、草原各自拥有完整站点 UI（导航、首页、相册页与查看器）；切换主题后当前路由和查看器状态保持，刷新后偏好恢复。
3. 两主题均符合两屏导航和主回忆控制契约，并通过共用的纯逻辑测试与各主题的浏览器流程测试。
4. 海边首屏实际使用 `react-liquid-glass-svg`，Chrome/Firefox 显示折射增强；Safari/iOS 与禁用增强时文字仍可读。
5. 在 1920×1080、2560×1440、390×844 视口验证两主题无横向溢出、焦点可见、滚动不会停在两屏中间；记录浏览器和结果。
6. `npm run check`、`npm run build` 和相关 Playwright 用例通过；SDD 规格、计划、任务、验证及需求/架构/module 文档同步实际边界。

## 取舍

不采用“共享页面骨架 + 主题 Slot”，因为它违反主题 UI 隔离；也不让主题各自复制交互逻辑，因为两屏与主回忆规则会漂移。纯交互契约是唯一共享层，确保体验一致而不共享任何可视 UI。
