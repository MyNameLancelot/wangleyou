# 紧凑主题切换与首屏文案精简设计

日期：2026-09-19  
状态：已确认，待实施

## 背景与目标

当前右下角主题开关默认尺寸偏大，图标语义也不够直接；首屏统计文案“7 个片刻 · 3 本相册 · 内容均为演示”不再需要。本次只收紧主题开关的形态并删除该行文案，不改变主题切换、首页两屏、路由或查看器行为。

## 已确认方案

采用方案 A：

- 默认形态为直径 40px 的圆形毛玻璃按钮，视觉上小而轻。
- 图标改为 ♻️ 风格的双箭头循环图形，但使用可控色彩的 SVG，不直接使用彩色 emoji。
- 鼠标悬浮或键盘聚焦时，按钮横向展开为约 128px 的胶囊长方形并显示“主题切换”。
- 动效只改变宽度、内边距和文字透明度；尊重 `prefers-reduced-motion`。
- 可点击区域保持至少 44×44px：40px 是玻璃表面的视觉直径，外层提供透明命中区域，避免牺牲触控与无障碍标准。
- 海边与草原分别维护独立组件和 CSS，不互相导入，也不共享 UI。
- 两套主题首页均删除“7 个片刻 · 3 本相册 · 内容均为演示”，且不保留空白占位。

## 视觉约束

- 海边：沿用蓝绿色文字、高透玻璃和冷色阴影。
- 草原：沿用深草绿文字、暖绿色玻璃和自然阴影。
- 默认状态只让循环箭头成为视觉焦点；展开状态的文字用于解释操作，不增加其他装饰。

## 验收条件

1. 两主题默认均呈现视觉直径 40px 的圆形循环箭头按钮，实际命中区域至少 44×44px。
2. 桌面 hover 与键盘 focus 时展开为约 128px 的胶囊，并显示“主题切换”。
3. 点击仍能切换主题、持久化偏好，并保持当前页面和查看器上下文。
4. 首页不再渲染演示统计文案，也不留下对应间距。
5. 桌面和移动端无横向溢出，焦点清晰，减少动态偏好生效。

## 验证

扩展 Playwright 用例验证默认尺寸、展开尺寸、图标语义、文字显隐、点击切换及统计文案缺失；随后运行 `npm run check`、`npm run build`、`npm run test:e2e` 与工作区 SDD 校验，并人工检查桌面截图。
