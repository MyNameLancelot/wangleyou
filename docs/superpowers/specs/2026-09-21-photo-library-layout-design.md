# 照片目录布局设计

## 目标

将示例照片按“年份-相册名”收纳到 `public/media/photos/`，让每个相册目录自行维护相册和照片元信息；首页主回忆改为读取独立且显式排序的 `home-memory.json`。

## 已确认的约束

- 网站仍是纯静态 GitHub Pages 应用；不得引入后端、数据库或上传能力。
- 照片只有发布原图这一种资源，不生成、存放或引用缩略图。
- 相册照片及其元信息放在同一个相册目录中；以 `top` 加数字开头的照片优先展示，其余照片按文件名自然排序展示。
- 主回忆的条目和顺序只来自 `home-memory.json`，不从相册按日期派生，也不设置“最新 12 张”的上限。
- 主题背景、背景音乐和视频不属于本次照片目录迁移。

## 文件布局

```text
public/media/photos/
  home-memory.json
  2024-05-Sequence00-破壳/
    meta.json
    001.jpg
    002.jpg
  2024-08-Sequence01-百日/
    meta.json
    001.jpg
    002.jpg
  2025-05-Sequence00-周岁/
    meta.json
    001.jpg
    002.jpg
```

不维护手写的 `index.json`。构建期 Node.js 脚本扫描 `public/media/photos/` 的一级相册目录，按目录名排序并生成发布产物中的相册索引。浏览器不能枚举静态目录，运行时只读取这个生成索引；索引不重复相册或照片元信息，也不作为维护者编辑的事实来源。

每个 `meta.json` 只记录同目录照片的元信息，以照片文件名为键，提供可选的拍摄日期、说明与替代文本等字段；它不声明照片列表或顺序。相册目录名固定为 `YYYY-MM-SequenceNN-相册名`：年份、月份和两位序列号共同决定全站排序，`SequenceNN` 使同月多相册的顺序稳定；解析器只截取前三个连字符字段，剩余文本完整作为相册名，因此相册名可以包含连字符。目录名只提供月份粒度，不能据此虚构 `YYYY-MM-DD` 日期。构建脚本只收集目录内受支持的图片文件：以 `top` 加数字开头的文件（如 `top01.jpg`、`top02.jpg`）排在最前，并按该数字升序；其他文件再按自然文件名排序（例如 `2.jpg` 在 `10.jpg` 前）。脚本将排序后的路径与对应元信息组合为相册媒体列表；该排序不影响 `home-memory.json` 的显式主回忆顺序。视频如保留，仍由相册目录的 `meta.json` 显式声明其发布路径和海报；它不参与照片文件发现。

`home-memory.json` 保存首页主回忆的完整照片元信息与显式播放顺序。条目引用已存在的 `photos/<目录>/<文件>`，不复制图片；它可选择相册未展示的照片，但本次示例只复用相册照片。

## 加载与校验

构建期脚本扫描相册目录、读取每个目录的 `meta.json`，按自然文件名顺序发现照片，生成发布索引并验证目录名、JSON 解析、字段、受支持图片、重复 ID 与引用资源存在。应用启动时读取生成索引和 `home-memory.json`，并在内存中组合为既有主题页面所消费的站点内容与主回忆数据；运行时仍校验获取结果、JSON、字段及主回忆照片类型。

任何配置获取、解析或校验失败时，应用使用已有的配置异常状态，不渲染部分不可信内容或白屏。构建期内容校验同样读取这些文件，验证所有目录声明、JSON 结构和引用资源存在。

## 模块边界

- `content` 负责发现、加载、校验并提供相册内容；不遍历文件系统，也不渲染 UI。
- `albums` 继续只负责首页交互纯契约；其主回忆创建函数改为接收已校验的显式主回忆条目，不再扫描相册。
- 主题 UI 继续只依赖模块公开入口，不读取 JSON 文件或目录路径。

## 迁移与验证

现有 6 张示例照片平均迁入三个相册目录。目录名按 `YYYY-MM-SequenceNN-相册名` 命名，生成脚本按其解析出的时间和序列排序；相册内 `topNN` 照片优先、其余照片按文件名自然排序展示。删除旧的顶层示例照片和 `public/media/thumbs/` 中的示例缩略图及其配置引用。同步移除 `src/content/albums.json`。

验证覆盖：配置与资源校验、内容加载的错误边界、主回忆显式顺序、相册数组顺序、现有浏览和查看器行为、生产构建及两套主题的浏览器路径。README、需求基线、总架构与受影响模块说明必须反映新的维护方式。

## 非目标

- 不根据目录或文件修改时间自动生成相册或日期。
- 不增加内容管理界面、上传、删除或在线编辑。
- 不迁移主题私有资产，也不改变主题视觉或查看器交互。
