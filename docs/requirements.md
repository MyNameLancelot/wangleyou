# 产品需求与验收基线

本文记录当前产品范围和验收行为；模块实现见 [总架构](architecture.md)，维护步骤见 [README](../README.md)，变更流程见 [SDD 指南](sdd.md)。网站已采用唯一的线缝相册主题，背景音乐保留但停用；原生设备验证状态见本文末尾。

## 目标与范围

网站中文名称为“王乐悠”，完整显示名称为“王乐悠 · 成长相册”。它是公开访问的静态家庭影像网站，记录孩子成长和家庭生活，以温暖、明亮、整洁的界面浏览照片、相册和视频，兼容 PC、手机、平板及独立原生 WebView 壳。

- 源码、素材和配置在 GitHub 仓库维护，更新内容后重新构建发布到 Cloudflare Pages 和 GitHub Pages。
- 不提供登录、家庭权限、在线上传/删除/编辑、业务后端、数据库、社交、评论、点赞或 AI 识别。不把前端密码或隐藏链接当作访问控制。
- 本期不使用付费服务，不实现原生 JS 桥接或离线媒体库；存储与托管升级须先取得用户确认。
- 未经用户明确指示，不推送代码或公开发布站点、安装包。

## 页面与浏览

### 首页

- 居中的奶油色相册书页带酒红封边和左侧线缝装订。桌面左上标题为「把日子，一页页翻开」，小字为「那些珍贵的时光，慢慢再看一遍」，均无句号；右上有「浏览全部影像」。手机标题分为「把日子，」「一页页翻开」两行，小字在照片上方，入口在照片下方。无页码、数量或进度文案，无常驻全局顶部导航。
- 页面普通滚动，不拦截滚轮或上下方向键。主回忆仅消费 `media-source/home-memory.json` 的显式照片及数组顺序，不接入查看器、不改写其队列。无可用照片时显示明确空态。
- 主回忆采用横向 3:2 等大层叠内页，照片随纸页轻微倾斜；内页总数为照片数加一。前翻减少右侧待翻页，回翻恢复。仅首页展示框允许非 3:2 照片居中裁切，详情和查看器完整显示原图。
- 桌面提供上一页、播放/暂停、下一页；手机隐藏按钮，在照片上横滑翻页、点击暂停或继续。每页静止停留 2 秒后前翻，动效约 900ms，落定后重新计时；手动翻页重置正在运行的周期，暂停时不新建计时器。
- 最后一页显示「翻到这里，先把书轻轻合上。这些日子没有走远，想念的时候，随时回来看看」，停止自动播放且不循环，允许手动回翻。
- 前翻从右向左卷起，曲线纸背和柔和投影随折线移动，回翻逆向展开；动效限制在内页内，不遮挡标题或伸出相册，期间拒绝重复动作。减少动态效果时直接切换，自动翻页不引入朗读。
- 仅页面可见、有下一页、未暂停、指针与焦点未停留播放器且查看器未打开时计时。显式继续可临时覆盖当前悬停/焦点暂停，直到指针或焦点离开。页面隐藏、打开查看器或卸载时清理计时器，回前台等待用户继续。

### 相册索引与留影页

- 支持多个相册。相册索引展示标题、日期、简短描述和最多三层向右上错位的封面；第一层完整显示，后两层仅露出上侧和右侧边缘。索引封面为 3:2 框，按原比例完整显示，非 3:2 素材留边，空相册有占位。
- 留影页（`#/browse`）使用与米黄页面底色融合的主题头图，不露出方形色块，标题为「留影」。平板和桌面在标题上方提供带左箭头的「返回首页」（`#/`，44px 命中区）；手机（≤600px）隐藏该入口，以浏览器返回手势返回，文案在 hero 剩余高度内居中。
- 提供“全部 / 照片 / 视频”筛选和按年份分组的相册卡；照片筛选保留含照片的相册，视频筛选保留含视频的相册。年份从新到旧，同年按目录月份与 `sequenceNN` 升序排列。点击卡片进入相册，不直接打开查看器。
- 留影卡片最多三层，按构建期媒体顺序取前三个可用且不重复的缩略图或视频封面。照片用 `srcSet`，视频用 `posterSrcSet`；手机/平板两列、桌面三列，复用现有 480w/960w 候选，不新增派生尺寸。
- 留影封面为 3:2，当前每册排序后的前三张发布图片均为 3:2；以 `cover` 铺满，后两层从右上露出，无白边、下方投影或悬浮缩放。此规则不改变索引封面、详情与查看器的完整显示。索引和留影的封面均不叠加视频播放角标。
- 说明条紧凑单行，桌面/平板显示相册名与说明；手机只显示相册名，深色底框贴合文字，不保留分隔线。留影页不展示媒体/年份数量、相册快捷列表、排序或键盘提示、逐张演示角标。
- 内容区和 hero 共用最大宽度及左右边距。≤900px 隐藏左侧定位栏，改用页面内年份导航；手机固定 hero、筛选和年份导航，列表预留空间，年份定位不被固定操作区遮挡。桌面年份按钮悬浮色与类型筛选选中态一致。

### 相册详情

- 副标题取 `description`，其下引言取 `opening`，缺省回退为 `description`。桌面 hero 实际可见高度为 360–400px，使 900px 高视口首屏可见更多图片；手机和平板采用紧凑高度。桌面/平板提供「返回留影」，手机隐藏该入口。
- 照片与视频按构建期媒体顺序混排，使用原始比例的响应式 WebP 瀑布流，不固定 4:3、不裁切；点击进入共用查看器。列数与间距按图库容器宽度取值，`sizes` 自动按实际列宽生成：

| 容器宽度 | 列数 | 间距 |
| --- | --- | --- |
| ≥1200px | 5 | 20px |
| 600–1199px | 4 | 15px |
| 300–599px | 3 | 10px |
| <300px | 2 | 5px |

- 典型视口：1440px 桌面五列、820/1024px 平板四列、390px 手机三列。照片为白色相纸底衬：8px 留白、8px 圆角、主题色轻投影（约 `0 5px 14px` 加 1px 发丝阴影），不加描边或边框；留白计入列宽，不改变上述档位。
- 视频缩略图使用真实帧或构建期占位封面，中央叠加凸起的通透玻璃圆钮：半透明白色磨砂渐变、模糊、顶部高光、柔和投影及灰色实心 Play 图标；桌面 38px、手机 26px，不支持模糊时用更不透明白底。角标不烘焙进资源。
- 演示相册仅在详情元信息标注“演示相册”。空相册、无效相册地址、加载中及资源失败均有明确反馈和可用返回入口。

## 媒体查看与播放

- 相册影像使用全站唯一共用查看器，黑色不透明背景、无主题入口。主题只挂载，不覆盖样式或功能，不复制实现；首页主回忆不接入。
- 打开定位所点击媒体；照片原比例完整显示，视频使用浏览器原生控制条，支持播放/暂停、进度、静音/音量与平台全屏。视频优先内联，只预加载元信息；打开时尝试播放，被拒绝时留在当前项，由原生控件提供主动播放入口。
- 工具栏只保留幻灯片和全屏，所有视口均隐藏放大、缩小、关闭和库的缩略图开关按钮。上一项/下一项仅 ≥1200px 显示；手机和平板使用横滑。支持左右方向键和双击/双指缩放，桌面滚轮不切图。
- 队列不循环，首尾禁用相应操作，单张无无效切换，空相册不打开。幻灯片仅由工具栏显式启动，默认不自动播放；视频自然结束停留当前项，不自动推进。
- Esc、黑色背景点击或返回可退出；点击影像和控件不退出。缩略图带默认展开，其上方有屏幕同宽的收起条，用向下/向上箭头表示收起/展开，不遮挡画面与寄语。
- 寄语来自 `photos_meta.captions`，位于当前影像实际渲染区域左下角，左右/底部留距约 12px，条宽贴合文字且不超过影像宽度减 24px；使用深色半透明模糊圆角底和左对齐文字，无寄语不留空位。
- Tab 焦点在查看器内循环，键盘焦点环固定白色；关闭后回到触发元素。无可见数量计数器，当前项通过「第 N 项，共 M 项」的可访问名称表达。
- 元素级全屏只展示影像，隐藏工具栏、导航、缩略图、收起条和寄语；进出全屏后恢复容器焦点，键盘/横滑仍可切图。不支持 Fullscreen API 的平台隐藏全屏入口，视频仍按原生控件能力处理，照片保持覆盖视口的沉浸层，不模拟系统全屏。
- 页面进入后台暂停幻灯片和视频，回前台等待主动继续；切换、关闭、路由变化或卸载清理旧媒体、监听及计时任务。快速切换时旧媒体异步结果不得影响当前项，区分播放意图、实际状态和临时暂停原因。
- 媒体加载失败使用查看器默认错误状态，可手动切换或关闭后重新打开，不无限跳过，不增加自定义错误/重试面板。
- 背景音乐固定资产、状态/命令和音频组件保留，但全站不挂载、不显示按钮或音量、不创建 audio、不尝试播放。重新启用须另行确认；音源协调能力继续保留，关闭后不得残留播放。

## 内容与媒体规则

内容配置与 UI 分离，维护步骤见 [README](../README.md)。原始素材提交仓库但不进入站点发布产物；构建期生成的索引和发布媒体不手写。

- 相册源目录为 `media-source/YYYY-MM-sequenceNN-相册名/`，`sequence` 小写；照片、视频、可选封面源图共用该层，不设 `photos`/`video` 中间层。新增目录、素材和 `meta.json` 即可增加相册，无需改 UI。
- 相册 `meta.json` 只允许 `album` 和 `photos_meta` 两段。`album` 可含 `title`、`date`、`description`、`opening`：标题缺省取目录后缀，日期缺省取目录年月并允许只到月；描述最多 16 个字符含标点，引言为 1–20 个非空白字符。
- `photos_meta.captions` 按照片或视频文件名登记寄语，只允许 `fileName`、`caption`；寄语为 1–60 个非空白字符，允许只覆盖部分媒体。未知字段、未知文件、重复登记和给封面保留名登记寄语均报错。
- 构建期相册索引按目录年月和序号降序生成；留影页同年升序展示的规则见页面章节。照片与视频统一按 `topNN` 编号升序优先，再按其余文件名自然序排列；该媒体数组是详情和封面取图的唯一顺序，不按拍摄日期或文件修改时间重排。首页采用自己的显式数组顺序。
- 相册 ID 全局唯一，媒体 ID 由文件名生成并在相册内唯一；跨相册使用相册 ID + 媒体 ID。标题、类型、ID、资源地址必须有效；可选日期、说明、替代文本、尺寸、时长按模型校验，日期不得从文件修改时间推断。封面未指定时使用可用缩略图/视频封面，空册占位。
- 照片按内容哈希生成不超过源宽的 480/960/1600/2560 宽度 WebP；源宽不足 480px 时以实际源宽生成一个候选。不放大、保持比例（允许整数像素舍入至多一像素）；输出到同名 `public/media/<相册目录>/`。不改源素材，未变化图片不重复编码，本地与 CI 缓存缺失时可完整重建。
- 视频由维护者离线准备为 H.264 + AAC、faststart 的 MP4；HEVC、MOV、WebM 等先转码。所有端共用同一容器；构建、CI、运行时不转码、不抽帧、不依赖 ffmpeg/ffprobe。发布 MP4 带内容哈希，字节未变且目标已存在时不重复复制；单文件 >100 MB 警告、>200 MB 构建失败，Git 普通推送另受单文件限制。
- 可在视频同目录提供 `<视频同名>.poster.jpg`（亦接受 jpeg/png/webp）真实帧；缺失时生成 16:9 深色中立占位封面，不因此失败。视频索引始终有 `poster`、同宽高比 `posterSrcSet` 和封面尺寸；不探测实际视频画幅。MP4 扩展名不区分大小写，视频 stem 与封面关联保持大小写；同 stem 多视频或一个视频多个封面须明确报错。孤立封面、非法容器、体积超限或候选比例错误须定位并使构建失败。
- 主题头图及保留的音乐在 `public/media/themes/book/`，不进入相册配置。提供可访问的演示相册、照片和视频，并说明外部素材来源和使用条件；来源未确认的演示音乐仅作非商业占位。
- 重复 ID、错误配置和显式引用的本地文件缺失必须阻止构建并定位字段；运行时网络失败在页面内反馈，不使应用白屏。

## 视觉、可访问性与性能

- 唯一 `book` 主题与 Android 酒红相册图标/开屏呼应：奶油纸页、酒红封边、线缝装订；无主题切换入口、行为或偏好存储。页面/卡片/按钮由主题负责，共用查看器不主题化。避免过多装饰、强烈渐变和复杂动效，关闭装饰、字体或动画仍可操作。
- 展示文字和图片默认不可选择，图片不可原生拖拽；输入框、文本框与可编辑区域保留选择。复制例外须由具体功能规格声明。
- 缩略图无内外描边，键盘焦点以轻微提亮和约 2px 上浮表达，保留 Enter/Space 打开语义。详情白色相纸底衬是唯一相框例外，内层不加边框。
- 指针点击后按钮、链接、表单、视频和对话框无默认焦点框；键盘操作仍有明确指示，普通控件使用主题色焦点环，查看器固定白色，缩略图采用上述替代指示。链接悬浮不变为深色/黑色描边。
- 按钮和按钮样式链接在默认、悬浮、聚焦、按下、禁用状态均无边框，透明占位边框也禁止；用底色、圆角、投影或字重区分。次要按钮悬浮/聚焦/按下保持底色和文字色。毛玻璃表面不加白色描边或白色高光边。
- 约 360px 手机、平板和常见桌面无意外横向滚动；适配横竖屏、安全区、触屏、鼠标及键盘。关键操作不只依赖悬浮，控件具有可访问名称和易触达的命中区，文字对比度清晰。
- 尊重减少动态效果偏好，对全屏和自动播放做能力检测与降级。浏览器模拟、原生模拟器和真机验证分别记录，不推断未验证兼容性。
- 列表优先缩略图，图片懒加载并预留尺寸，大图按需加载、合理预加载邻项，不一次加载整册原图/视频；页面切换和销毁释放事件、计时器与媒体。
- 页面与交互以用户最新口述和活动规格为准，不维护外部设计稿；变更确认与浏览器核对规则统一见 [SDD 指南](sdd.md)。

## 静态部署与原生 App

- 前端采用 React + TypeScript + Vite、Node 24/npm，运行产物仅静态文件，无 Node 服务。兼容开发、静态预览、根路径与仓库子路径，Hash 路由无需服务端动态重写。
- `main` 是唯一正式发布分支：GitHub Actions 检查后部署 `/wangleyou/`；Cloudflare Pages Git 集成从 main 构建根路径，分支预览不更新正式地址。
- 媒体配置仅保存安全的 `media/...` 相对路径，禁止协议、绝对路径、反斜杠、查询、片段和目录穿越。媒体解析优先 `VITE_MEDIA_BASE_URL`，缺省用 Vite `BASE_URL`，不改变页面 base 或 Hash；目前两处生产站点均不设置媒体前缀，媒体同源。
- 媒体增长时核实托管容量/单文件/流量限制；升级触发与候选见 [总架构](architecture.md)，不假设无限容量或擅自迁移存储。
- iPhone/iPad 和 Android 原生包默认加载 `https://wangleyou.pages.dev/`，GitHub Pages 是浏览器备用入口。安装包仅含原生容器、图标、故障界面及 Android 本地开屏视频，不含网站 HTML/JS/CSS、相册配置或家庭媒体。
- 顶层导航仅允许上述 HTTPS 根路径，Hash 留在 WebView；用户点击的外部 HTTPS 交系统浏览器，其他 scheme 不执行。Android 返回先退出视频全屏、再关闭查看器、再回站内历史；iOS 支持返回手势。照片、MP4、安全区、旋转和 iPad 宽屏按平台能力可用。
- Android 桌面名为「乐悠时光」，图标为无文字酒红翻开相册和奶油白底，相册、纸页与主要阴影在圆形/圆角裁切内完整显示，系统冷启动与桌面使用同一图标资源；家庭交付文件名为 `乐悠时光-v<versionName>.apk`。Android 仅 INTERNET、禁用明文流量；iOS 保持默认 ATS。
- 容器展示主页面加载进度，断网、HTTP 错误或站点不可用时有重试；主框架加载和失败期间，辅助功能只访问当前原生界面，不访问底层旧页面或系统错误页。Android 状态栏透明，背景延伸至时间/电量后方，交互内容避开开孔及系统栏。
